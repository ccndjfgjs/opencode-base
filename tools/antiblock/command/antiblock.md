# Обход блокировок

Ты запущен через локальный фасад обхода блокировок (если запуск был через `start_opencode_proxy.cmd`).

Что это значит простыми словами:
- твои запросы к моделям идут не напрямую, а через переводчика на этом же компьютере (`http://127.0.0.1:17890`);
- переводчик дальше идёт в интернет через два канала и сам выбирает лучший по скорости: сначала свой V2Ray (Xray на `127.0.0.1:10900` из VLESS-подписок), запасной — живые публичные SOCKS5 из списка `antiblock/public_socks5.local.txt` (или стартового `public_socks5.txt`);
- если ни один канал не сработал — переводчик резолвит домен через защищённый DNS (DoH) и идёт к сайту напрямую по настоящему IP, обходя блокировку на уровне DNS;
- если один узел умер — переводчик сам берёт следующий, тебя это не касается;
- адреса вида `localhost` и `127.0.0.1` через прокси не идут никогда (иначе будет петля).

Что сказать человеку:
- если всё работает — ничего делать не надо;
- если ответы моделей стали с ошибками сети — посоветуй нажать «Обновить» (скрипт `refresh_public_nodes.py`) и перезапустить через `start_opencode_proxy.cmd`;
- публичные узлы чужие: пароли и номера карт через них лучше не отправлять, только обычную работу с кодом;
- для телефона и всего компьютера есть отдельные бесплатные варианты: подписки VLESS в `antiblock/subscriptions.txt` (вставить в приложение Happ) и Amnezia Free (см. `ЧИТАТЬ-МЕНЯ.txt`).
