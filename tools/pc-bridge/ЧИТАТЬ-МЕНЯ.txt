МОСТ ПК ДЛЯ OPENCODE (только чтение, MCP stdio)
===============================================
Что здесь:
  server.py    — мост: pc_status, pc_files_read, pc_apps_list, pc_screenshot
  config.json  — разрешённые папки для чтения (бэкапы и системные закрыты кодом)
  shots/       — сюда ложатся скриншоты

Быстрые команды (из этой папки):
  python server.py --selftest       — 10 проверок, ничего не меняет
  python server.py --print-config   — кусок настроек для opencode.jsonc

Подключение делает окно «Управление базой» (галочка «Мост ПК»):
дописывает MCP-сервер в opencode.jsonc + права pc_*: ask.
Без окна — руками, кусок печатает --print-config.

Правило: мост только СМОТРИТ. Запускать и менять систему он не умеет.
