# Карта базы — что здесь лежит

Этот файл — путеводитель по базе. Он читается в начале работы, чтобы сразу
понимать, где что искать. Здесь только **что где лежит** — правила поведения
лежат отдельно, в `ПРАВИЛА-ИИ.md`.

## Куда что писать — короткая шпаргалка

| Что случилось | Куда писать |
|---|---|
| Узнал факт о пользователе | `profile.md` |
| Приняли решение, о котором нельзя забыть | `facts.md` |
| Начали новый проект | строка в `projects.md` + папка в `projects\` |
| Узнал что-то по теме (ремонт, учёба, деньги) | `знания\<Область>\` |
| Задача про код или безопасность | `знания\Техника\Безопасность\_подсказки-безопасность.md` и `знания\Учёба\_подсказки-программисту.md` — сначала карта, потом нужные файлы |
| Нужно завести карточку человека | `знания\Люди\<группа>\` |
| Банк, карта, подписка, долг, налог | `знания\Деньги\` |
| Документ, страховка, срок действия | `знания\Документы\` |
| Врач, лекарство | `знания\Здоровье\` |
| Техника, машина, жильё, гарантия | `знания\Имущество\` |
| Что делать в беде, кому звонить | `знания\Экстренное\` |
| Ценная мысль, которую надо найти потом | `библиотека\записи\<Тема>\` |
| Закончилась важная работа | `sessions\<месяц>.md` |
| Поменяли правило поведения | `ПРАВИЛА-ИИ.md` |
| Нужна новая привычка ассистента | `skills\<имя>\SKILL.md` |
| Что делает тот или иной скилл | `skills\_ОПИСАНИЕ-НАВЫКОВ.md` |

Не знаете, куда записать личные данные — откройте
`знания\_ЛИЧНЫЕ-ДАННЫЕ.md`: там таблица «что → куда».

## Разделы базы

### Корень — самое важное

```
profile.md            кто пользователь, как с ним общаться
facts.md              правила и решения (главный файл, читается всегда)
projects.md           список всех проектов, по строке на проект
КАРТА-БАЗЫ.md         этот файл
ПРАВИЛА-ИИ.md         как ассистент должен себя вести
ОБРАЗЕЦ-БАЗЫ.md       подробный образец устройства базы
созданные-базы.json   список баз, созданных программой
debug.log             технический журнал плагина
```

Эти файлы читаются при каждом запуске, поэтому в них — только стойкое
и важное. Временные детали сюда не пишутся.

**Эти файлы нельзя переносить в другие папки.** Каждый из них
привязан к корню по имени — программа и плагин ищут их именно здесь:

| Файл | Почему он в корне |
|---|---|
| `profile.md`, `facts.md` | по ним плагин понимает, что папка — это база |
| `profile.md`, `projects.md`, `facts.md`, `КАРТА-БАЗЫ.md`, `ПРАВИЛА-ИИ.md` | перечислены в настройках автоподключения |
| `ОБРАЗЕЦ-БАЗЫ.md` | по нему создаются новые базы |
| `созданные-базы.json` | программа ведёт этот список в корне базы |
| `debug.log` | плагин пишет журнал по этому пути |

Перенесли — база перестанет читаться. Если корень кажется
захламлённым, помните: это не беспорядок, а рабочее место программы.

### память\ — короткая сводка

```
память\
├── АКТИВНАЯ-ПАМЯТЬ.md   что происходит прямо сейчас, читается автоматически
└── архив\               старые сводки, чтобы не терять историю
```

`АКТИВНАЯ-ПАМЯТЬ.md` — это короткая записка «на чём мы остановились».
Перед завершением большой работы ассистент обновляет её. В новой сессии
он открывает этот файл первым и сразу понимает контекст.

### библиотека\ — знания с поиском

```
библиотека\
├── индекс.json          перечень всех записей, ведётся автоматически
├── КАТАЛОГ.md           то же, но читаемое глазами
├── записи\<Тема>\*.md   полные знания по темам
├── входящие\            новое, ещё не разобранное
├── архив\               устаревшее, но нужное
├── журнал\              что и когда менялось
└── шаблоны\             заготовки для новых записей
```

Это раздел для знаний, которыми управляет сам ассистент: он их ищет,
добавляет и обновляет. Одна запись — один файл.

### знания\ — материалы по областям

```
знания\
├── Техника\        компьютеры, программы, устройства
├── Деньги\         счета, платежи, покупки, накопления
├── Здоровье\       самочувствие, лекарства, врачи, спорт
├── Учёба\          курсы, книги, конспекты
├── Дом-и-быт\      ремонт, рецепты, техника для дома
├── Документы\      справки, договоры, важные бумаги
├── Люди\           карточки людей: семья, друзья, коллеги
├── Имущество\      что есть: техника, транспорт, жильё
└── Экстренное\     что делать и кому звонить в беде
```

Правило простое: **одна область — одна папка**. Внутри — свои файлы,
можно вкладывать глубже: `знания\Дом-и-быт\Ремонт\плитка.md`.

Нужна своя область — просто создайте папку с понятным названием.

Эти файлы **не читаются при каждом запуске** (иначе база раздуется).
Ассистент достаёт их по необходимости — поиском или по прямой просьбе
«посмотри в знаниях про ремонт».

### Заготовки личных данных

В областях лежат пустые заготовки — файлы, имя которых начинается
с `_ШАБЛОН-`. Внутри — поля с пустыми строками под заполнение.

Как пользоваться:

1. Открыть нужную область (например, `знания\Люди\Семья\`).
2. Скопировать файл `_ШАБЛОН-….md`.
3. Переименовать в понятное имя: `Мама.md`, `Сбер.md`.
4. Заполнить. Пустые строки можно оставить — допишете позже.

Заготовки не трогайте и не удаляйте — по ним удобно заводить
новые карточки. Ваши записи называйте обычными словами, без `_`.

Общая шпаргалка «что куда писать» — `знания\_ЛИЧНЫЕ-ДАННЫЕ.md`.

**Чего в этих файлах быть не должно:** пароли, номера карт,
ПИН-коды, коды из СМС, серии и номера документов, их сканы.
Файлы базы уходят нейросети на чужой сервер. Пишите, *где* лежат
данные, а не сами данные.

### Что чем отличается — области знаний

| Область | Для чего |
|---|---|
| `Люди\` | кто есть кто: семья, друзья, родня, коллеги, специалисты |
| `Деньги\` | банки, карты, подписки, долги, налоги |
| `Документы\` | паспорта, страховки, сроки действия |
| `Здоровье\` | врачи, лекарства, самочувствие |
| `Имущество\` | техника, транспорт, недвижимость, гарантии |
| `Экстренное\` | что делать и кому звонить в беде |
| `Дом-и-быт\` | ремонт, рецепты, быт |
| `Техника\` | как устроены программы и устройства |
| `Учёба\` | курсы, книги, конспекты |

### projects\ — работа

```
projects\
└── <Название проекта>\
    ├── _проект.md      описание, этапы, состояние
    ├── задачи.md       что нужно сделать
    ├── файлы.md        где что лежит
    └── <Нейросеть>\    папка под каждую программу
        ├── work.md         что эта программа сделала
        └── sessions.md     автожурнал её сессий
```

Один проект — одна папка. Новый проект: создать папку, положить
`_проект.md`, добавить строку в `projects.md`.

### личное\ — про вас, не про работу

```
личное\
├── цели.md         чего хочу достичь, сроки
├── привычки.md     что делаю регулярно и как идёт
├── идеи.md         приходящие мысли, ещё не проекты
└── дневник\        записи по датам
```

Здесь всё, что не относится к проектам и темам: планы, намерения,
размышления. Временные бытовые заметки — не сюда, а в `знания\`.

### sessions\ — журнал работы

```
sessions\
└── 2026-09.md      всё, что делалось в сентябре 2026
```

Один файл на месяц. Сюда пишется, что сделано, чтобы потом можно
было вспомнить ход работы.

### журнал-решений\ — история изменений

```
журнал-решений\
└── 2026-09.md
```

Отличается от `sessions\`: там — что делали, здесь — **почему так решили**
и что поменялось в самой базе. Когда через месяц возникнет вопрос
«а почему у нас так?» — ответ будет здесь.

### настройки\ — как ассистент себя ведёт

```
настройки\
├── стиль-общения.md    тон, длина ответов, обращение
├── запреты.md          что делать нельзя никогда
└── разрешения.md       что можно делать без спроса
```

Если правило большое и постоянное — оно идёт в `ПРАВИЛА-ИИ.md`.
Здесь — частные настройки по темам.

### инструкции\ — как устроена база

Подробные объяснения по каждому разделу. Читается человеком,
когда нужно разобраться.

### skills\ — умения ассистента

```
skills\
└── <имя скилла>\
    └── SKILL.md
```

Скиллы подхватываются автоматически. Новый скилл — папка с `SKILL.md`
внутри: в шапке `name` и `description`, дальше инструкция.

Что делает каждый скилл, когда он включается и что получается на
выходе — в файле `skills\_ОПИСАНИЕ-НАВЫКОВ.md`. Там же — как навык
попадает в работу (в том числе почему новый навык виден только после
перезапуска OpenCode).

Новый скилл появляется в работе **только после перезапуска OpenCode**:
он читает папку навыков при запуске. Править навык нужно в базе,
а не в `~\.config\opencode\skills\` — правку перезапишет синхронизация.

Папка `S T A L K E R` переименована в `stalker-roleplay` (сентябрь
2026): имя с пробелами opencode не принимает, поэтому теперь это
полноценный 15-й скилл с шапкой `name/description`.

### tools\ — программа и образец моста

Здесь лежит сама программа управления базой и всё, что ей нужно
для работы. В корень базы это не выносится: там рабочее место.

| Что | Зачем |
|---|---|
| `tools\dbapp\` | окно «Управление базой»: создание базы, подключение, мост |
| `tools\ncp-bridge\` | образец моста NCP — из него создаётся рабочий мост |
| `tools\` (прочее) | вспомогательные файлы программы |

`tools\ncp-bridge\` — это **образец, а не рабочий мост**. Он едет
вместе с базой и нужен, чтобы программа могла создать мост на любом
компьютере, ничего не скачивая. В нём вместо пути к библиотеке стоит
пометка `{{LIBRARY}}`: настоящий путь программа подставляет сама,
когда создаёт мост в выбранной человеком папке.

## Что чем отличается — чтобы не путать

| Раздел | Для чего | Кто ведёт |
|---|---|---|
| `facts.md` | стойкие решения | человек и ассистент вместе |
| `память\` | что сейчас происходит | ассистент сам |
| `библиотека\` | знания с поиском | ассистент сам |
| `знания\` | темы и материалы | человек |
| `projects\` | работа над проектами | вместе |
| `личное\` | цели, привычки, дневник | человек |
| `журнал-решений\` | почему так решили | ассистент сам |

Главное правило: **если не знаете, куда записать — спросите ассистента**,
он подскажет по этой карте.

### Программы, к которым подключается база

Программа управления ищет программы сама — от домашней папки
и переменных среды, без вписанных путей. Программ ровно две,
сторонних нет по решению пользователя (сентябрь 2026):

| Программа | Увидит базу? | Через что |
|---|---|---|
| OpenCode | да | `AGENTS.md`, `opencode.jsonc`, плагин памяти и навыки |
| Harness | да | файл `AGENTS.md`, папка `skills` и мост NCP |

### Мост NCP — для обеих программ

Мост — маленькая программа-переводчик. Она умеет говорить на языке
MCP и читает библиотеку прямо из базы.

Смысл в том, что **базу при этом не трогают**: мост лежит отдельно,
а библиотека остаётся на месте и в одном экземпляре. Двух копий
знаний не появляется.

| Что | Где |
|---|---|
| Рабочий мост | там, где выбрал человек — путь ни к чему не привязан |
| Образец моста | `tools\ncp-bridge\` внутри базы |
| Подключение к opencode | готовые кнопки на вкладке «opencode» |
| Подключение к Harness | YAML-оверлей с вкладки «Мост NCP», применить как `dsh --patch <файл>` |

Мост создаётся **в программе**: вкладка «Мост NCP». Там выбирается
папка для моста, библиотека и программа-получатель: opencode или
Harness. После создания программа сама прогоняет 18 проверок.

Если моста ещё нет, программа **сама предлагает его создать** сразу
после создания новой базы — чтобы человек не остался с базой,
которую никто не читает.

Что мост умеет сейчас: `ncp_status` (состояние), `ncp_search`
(поиск), `ncp_save` (сохранить запись). В протоколе описано семь
операций — остальные четыре добавляются по очереди, по возрастанию
риска.

**Правило, которое легко забыть:** после подключения мост нужно
проверить кнопкой «Проверить», а opencode — перезапустить: настройки
читаются при старте.

## Перенос на другой компьютер

Базу можно скопировать в другую папку или отдать другому человеку —
переписывать ничего не нужно. Самопроверка следит, чтобы так
и осталось: имени пользователя нет ни в одном рабочем файле.

- пути к программам считаются от домашней папки и переменных среды;
- `Управление-базой.cmd` сам находит Python с установленным PyQt6;
- в настройках и в готовых командах путь стоит пометкой `{{BASE}}`,
  а рабочий стол — пометкой `{{DESKTOP}}`; настоящие пути
  подставляются при подключении;
- плагин памяти находит базу сам, без вписанного пути;
- образец моста лежит в `tools\ncp-bridge\` и едет вместе с базой:
  мост можно создать на новом компьютере, ничего не скачивая.
  Python программа тоже ищет сама.

Поставить на новом компьютере нужно только Python с PyQt6.
Подробнее — в `tools\dbapp\ЧИТАТЬ-МЕНЯ.txt`, раздел «Перенос
на другой компьютер».

## Если что-то перенесли

Папку базы нельзя перемещать. Если перенесли — запустите
`Управление-базой.cmd` в корне базы и подключите её заново:
путь к базе записан в настройках программы подключения,
и его надо обновить.
