# Краткие ответы через caveman

## Когда брать

- Просят отвечать **коротко**, «без воды», «по-сути», «только суть».
- Ответы выходят многословными, а задача простая.
- Нужно убрать вступления, повторы и «подводки», оставив факты.

## Когда не брать

- Задача требует разбора: сократив объяснение, потеряешь смысл.
- Человек просит подробно, с примерами и обоснованием.
- Ответ пойдёт в документ или письмо, где нужна полная формулировка —
  краткость здесь навредит.

## Что это делает

Правила ложатся **в AGENTS.md** между нашими метками:

```
<!-- == OpenCode_Base: caveman == -->
…правила…
<!-- == OpenCode_Base: конец caveman == -->
```

Метки свои, чужие у разных установщиков свои — путать нельзя. Пока блок на
месте, правила действуют для всех ответов. Снятие — команда, а не просьба.

## Уровни

| уровень | ключ | что это |
|---|---|---|
| лёгкий | `lite` | базовые правила автора, режим `caveman`. **По умолчанию** |
| полный | `full` | режим `ultracave`, самая жёсткая ступень: куски фраз, каждый факт один раз |

**Открытое допущение, не подтверждённое решением.** Уровень выбирается не
в окне программы, а командой. Галочка на вкладке opencode ставит лёгкий
уровень. Полный включается только вручную:

```bash
python tools/dbapp/caveman.py install full
```

Снять и поставить обратно:

```bash
python tools/dbapp/caveman.py remove
python tools/dbapp/caveman.py install
```

Если человеку нужен другой уровень постоянно, спроси — и скажи ему команду,
а не меняй настройки молча.

## Команды

```bash
python tools/dbapp/caveman.py status      # стоят ли правила, какого уровня
python tools/dbapp/caveman.py install     # поставить (по умолчанию лёгкий)
python tools/dbapp/caveman.py install full # поставить полный уровень
python tools/dbapp/caveman.py remove      # снять
```

Код возврата: `0` — успех, `1` — ошибка, `2` — неизвестная команда.

## Как честно говорить о состоянии

1. `status` — скажет, на месте ли блок и какого он уровня. **Это правда.**
2. Уровень из ответа `status`, а не из того, каким ты его считаешь.
3. Не обещай экономию: заявленные автором 65–75% **не проверены**. В его же
   README у «caveman» — 3%, у «ultracave» — 35%. Называй это заявлением
   автора, а не своим измерением.

## Ошибки и что делать

| что сказал | что делать |
|---|---|
| `status` говорит, что блока нет | правила не действуют; скажи прямо, что краткость не включена |
| правила на месте, но ответы всё равно длинные | правила мягкие, это нормально; не обещай чуда, скажи честно |
| `install` вернул ошибку | перескажи текст ошибки; не пиши «включил» |
| блок в AGENTS.md повреждён | `remove` и `install` починят; предупреди человека, что правила на секунду снимутся |

Уровень `full` жёстче лёгкого заметно. Если человеку стало неудобно —
предложи `lite`, не молча переключай.

## Чего не проверено

- Реальная экономия токенов на этих правилах не измерялась.
- Совместимость с конкретной версией правил проверяется только `status`.

## Как выключить словами

Правила автора снимаются словами «stop caveman» или «normal mode» — это
написано у него в README. Программа их ставит, снимает команда `remove`.
