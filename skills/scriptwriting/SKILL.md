# Написание сценариев

## Принцип

Сценарий — это не текст, а машина удержания внимания. Каждая строка либо двигает историю, либо подсказывает картинку на экране, либо удерживает зрителя. Всё остальное — вычеркнуть.

## Когда применять

- сценарии видео для YouTube, Shorts, Reels, TikTok
- сценарии роликов и презентаций
- диалоги и катсцены для игр
- сторителлинг: истории для лендингов, питчи, озвучка

## Процесс: пять шагов

### Шаг 1: выясни вводные

Прежде чем писать, узнай (одним коротким вопросом, если не указано):
- **Формат и хронометраж**: ролик на 60 секунд? Видео на 10 минут? Презентация?
- **Аудитория**: кто смотрит, что уже знает, зачем смотрит?
- **Цель**: что зритель должен понять, почувствовать и сделать в конце?
- **Платформа**: YouTube, VK, внутренняя презентация, игра?

Если пользователь диктует голосом и чего-то не хватает — выбери разумное значение по умолчанию, скажи о нём и продолжай. Не устраивай допрос из пяти вопросов.

### Шаг 2: выбери структуру

Подбери структуру под формат и скажи, какую выбрал:

- **Хук → Обещание → Тело → Призыв** — для YouTube и любых видео, где зритель может уйти в первые 15 секунд.
- **Проблема → Усиление → Поворот → Решение → Доказательство → Призыв** — для рекламных и презентационных роликов.
- **Три акта**: завязка → противостояние → развязка — для игр, катсцен, длинного сторителлинга.
- **Список-обратный отсчёт** (5 способов…, топ-7…) — для обучающего и развлекательного контента.

### Шаг 3: напиши хук

Первые 5–15 секунд решают всё. Хук должен:
- задать вопрос или обещание, ответ на который зритель хочет узнать;
- быть конкретным, не абстрактным («этот скрипт экономит 3 часа в неделю», а не «скрипты — это полезно»);
- начинаться с середины действия или с сильного утверждения — не с приветствия и не с разгона.

Напиши 2–3 варианта хука и выбери лучший сам (или предложи по пунктам, если хук критичен для задачи).

### Шаг 4: напиши сценарий в формате «таблица»

Формат вывода — два столбца:

```
| ВРЕМЯ | ВИДЕО (что на экране) | ТЕКСТ (что звучит) |
|-------|----------------------|--------------------|
| 0:00–0:08 | Крупный план: рука жмёт Enter, экран мигает | «Этот скрипт написал отчёт за вас, пока вы пьёте кофе» |
```

Правила текста:
- **Пиши для уха**: короткие фразы, разговорные обороты, никакой канцелярщины. Прочитай вслух — запинаешься, переписывай.
- **Один абзац — одна мысль.** Каждая строка озвучки — законченная мысль, которую можно произнести одним дыханием.
- **Глаголы сильнее прилагательных.** «Скрипт собирает отчёт за 40 секунд» лучше «Скрипт очень быстрый и удобный».
- **Диалоги живые**: люди не говорят полными предложениями. «Ты это видел?» лучше «Ты видел то, что только что произошло?».
- **Пиши в конкретике**: числа, предметы, действия. Абстракция убивает внимание.

Правила видео-колонки:
- каждые 5–10 секунд на экране что-то меняется (кадр, графика, текст, движение);
- видео-колонка поддерживает текст, а не повторяет его дословно;
- отмечай, где нужен титр/заставка/графика, явно: `[ТИТР: …]`, `[ГРАФИКА: …]`, `[B-ROLL: …]`.

### Шаг 5: проверь ритм и закончи призывом

- Прочитай весь сценарий вслух и посчитай примерный хронометраж (средний темп речи: ~130–150 слов в минуту для русского языка). Не влезает в формат — сокращай, а не убыстряй.
- Каждые 20–30 секунд — мини-крючок: вопрос, обещание «дальше — главное», смена темы.
- Финал: один чёткий призыв к действию. Один. «Подпишись и поставь лайк, а ещё скачай гайд и загляни на сайт» — это уже три, зритель не сделает ни одной.

## Проверка качества перед сдачей

- [ ] Хук в первые 5–15 секунд цепляет конкретикой
- [ ] Формат таблицы: время / видео / текст заполнены для всего сценария
- [ ] Каждая строка озвучки произносится одним дыханием
- [ ] Нет канцелярита и абстракций, есть числа и действия
- [ ] На экране что-то меняется каждые 5–10 секунд
- [ ] Хронометраж сходится с заданным форматом
- [ ] В финале ровно один призыв к действию

## Типичные провалы

| Провал | Как правильно |
|--------|---------------|
| Начинать с «Всем привет, с вами…» | Начинать с сути: действия, вопроса, обещания |
| «Уникальный», «инновационный», «качественный» | Конкретика: «собирает отчёт за 40 секунд» |
| Стена текста без разбивки на кадры | Таблица: каждая строка — кадр |
| Пять призывов в конце | Один призыв |
| Сценарий, написанный «на глаз» по времени | Пересчёт: 130–150 слов/мин, лишнее — вычеркнуть |
| Диалоги-декларации («как ты знаешь, наш продукт…») | Живая речь с подтекстом и перебиваниями |
