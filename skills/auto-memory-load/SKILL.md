# Правило автозагрузки

В начале **КАЖДОЙ** сессии (до первого ответа пользователю) ты ОБЯЗАН:

1. Вызвать `memory_read()` — загрузит `profile.md`, `projects.md`, `facts.md`
2. Вызвать `library_status()` — узнать состояние библиотеки NCP  
3. Если в `projects.md` есть активный проект — вызвать `memory_search` по имени проекта

Только ПОСЛЕ этого отвечай пользователю. Не жди просьбы «проверь базу».
