# Работа с картами по правилам

Для всего, что связано с картами — отрисовка, показ данных, расстановка
меток, построение маршрутов, определение местоположения, — обязательны
следующие жёсткие правила.

- **Запрещено:** Google Maps, Apple Maps, Bing (зарубежная версия),
  OpenStreetMap с прямыми зарубежными тайлами, любой сторонний источник
  карт без нужного допуска; Mapbox, Leaflet + OpenStreetMap и подобные
  им замены.
- **Разрешено только:** Tencent Maps, AMap (Gaode), Baidu Maps,
  NASG Tianditu.
- Если пользователь не назвал поставщика карт — по умолчанию берутся
  карты Tencent; см. ниже «Быстрый шаблон для обычного случая».
- **Никогда** не вставляй, не подставляй и не протаскивай в код настоящий
  ключ доступа к картам. Готовый код с рабочим ключом не выдаётся.
- Правила обращения с ключом (различаются по случаям):
  - **Обычный случай** — пользователь ключ не даёт. Берём Tencent Maps
    GL JS и грузим набор из официального CDN **без** параметра `key`,
    оставляя его явной заготовкой, которую пользователь заполнит сам.
    Свои посредники для запросов не подставляются.
  - **Необычный случай** (пользователь оформляет свой ключ) — ставим
    явную заготовку
    `key="Оформите свой ключ на открытой платформе XX и замените эту заготовку"`
    (вместо XX — название нужной платформы).
  - **Исключение для зарубежных тайлов:** если просят показать
    зарубежную территорию — это считается необычным случаем.
- **Риск утечки ключа на стороне браузера:** ключ открытым текстом
  в браузерном коде можно перехватить. Для личного пользования настройте
  список доменов (Referer), для рабочего — проверка ключа должна идти
  через сервер.
- В этом окружении нет ни своего посредника для ключей, ни сервера.
  Код должен работать сам по себе: набор грузится из официального CDN,
  а ключ требуется от пользователя.

## Порядок работы

1. **Обычный случай.** Пользователь не назвал поставщика карт — или назвал
   Tencent и не просит использовать свой ключ. Берём Tencent Maps GL JS
   с официального CDN, параметр `key` оставляем заготовкой и говорим
   пользователю, где оформить ключ.
2. **Необычный случай.** Пользователь назвал AMap / Baidu / Tianditu —
   или назвал Tencent, но прямо просит использовать свой ключ. Берём
   названного поставщика, а ключ пишем явной заготовкой
   `key="Оформите свой ключ на открытой платформе XX и замените эту заготовку"`
   (вместо XX — название платформы). В ответе объясняем: а) шаги и адрес,
   где оформить ключ на соответствующей открытой платформе; б) как
   заменить заготовку полученным ключом и всё собрать.
3. **Поставщик не из списка разрешённых** (Google Maps, Apple Maps,
   Bing зарубежный, Mapbox, OpenStreetMap и прочие). Не отказывай сразу.
   Сначала объясни риск нарушения правил, затем назови конкретные причины,
   затем сам замени на разрешённую замену и выдай полный рабочий код.
   Замена делается по правилам пункта 1 или пункта 2 выше.

## Быстрый шаблон (Tencent Maps GL JS)

Набор грузится с официального CDN Tencent. Параметр `key` остаётся
заготовкой — настоящий ключ не подставляется, посредник не указывается.

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>Карта</title>
    <style>
        html, body { margin: 0; padding: 0; height: 100%; }
        #map { width: 100%; height: 100vh; }
    </style>
    <!-- Набор грузится с официального CDN; ключ остаётся заготовкой -->
    <script src="https://map.qq.com/api/gljs?v=1.exp&key=Please%20apply%20for%20your%20own%20key%20at%20the%20Tencent%20Maps%20Open%20Platform%20and%20replace%20this%20placeholder"></script>
</head>
<body>
    <div id="map"></div>
    <script>
        const map = new TMap.Map('map', {
            zoom: 12,
            center: new TMap.LatLng(39.984104, 116.307503),
        });
    </script>
</body>
</html>
```

Замечания к шаблону:

- В адресе набора есть параметр `key`, и его значение — всегда текст
  заготовки, никогда настоящий ключ.
- Если используемая версия набора предпочитает `TMap.setConfig()` вместо
  параметра в адресе — ту же заготовку ставьте туда. Не используйте оба
  способа сразу: вместе они дают пустую карту.
- Скажите пользователю, где взять ключ и что до замены заготовки карта
  останется пустой.

## После создания файла — показать его через present_files

Когда файл HTML для обычного случая записан, вызовите инструмент
`present_files`, чтобы показать его:

```
present_files(["/полный/путь/к/карта.html"])
```

Не заканчивайте работу на одном только `Write`; не запускайте
`python http.server`; не выводите текст этого навыка. Инструмент
`present_files` в этом окружении доступен всегда — вызывайте его сразу.

## Замечания для обычного случая

1. **Система координат**: GCJ-02 (координаты Марса).
2. **Высота контейнера**: у контейнера должна быть заданная высота
   (`height: 100vh` или значение в пикселях), иначе карта не отрисуется —
   особенно при гибкой разметке (flex).
3. **Ключ — всегда заготовка**: настоящий ключ не создаётся никогда.
   Пустая или серая карта почти всегда означает, что заготовку
   не заменили. Скажите об этом пользователю прямо, а не ищите другую
   причину.
4. **Следуйте официальной документации**: берите только те классы,
   свойства и события, что описаны в официальной документации и примерах
   Tencent Maps. Не выдумывайте их — при сомнении проверяйте документацию.
5. **Подключение наборов по необходимости**: для поиска мест, построения
   маршрутов и подобного добавляйте в адрес набора параметр `libraries`,
   например `/gljs?v=1.exp&libraries=service`.
6. **Правило маршрута — строкой**: `TMap.service.Driving({ policy: 'LEAST_TIME' })`;
   допустимые значения: `LEAST_TIME` / `LEAST_DISTANCE` / `AVOID_HIGHWAY` /
   `REAL_TRAFFIC`. Не используйте `TMap.constants.DRIVING_POLICY.xxx`.
7. **Служебные вызовы — только через классы набора**: построение
   маршрутов, поиск мест и подобное делаются классами набора, такими как
   `TMap.service.Driving` / `TMap.service.Search`. Не собирайте адреса
   служб вручную через `fetch(...)` — ручная сборка даёт ошибки
   (LatLng NaN / 403).
8. **Не используйте `mapStyleId`**: свои оформления (`style1` / `style2`
   и подобные) требуют отдельного включения в кабинете службы
   местоположения Tencent и не поддерживаются обычным ключом; при
   неверном использовании карта становится пустой и серой. Не передавайте
   `mapStyleId` при создании `new TMap.Map()` — берите обычную векторную
   основу.
9. **Правило имён классов GL JS**: классы слоёв (управляют несколькими
   фигурами одного вида — Marker / Polyline / Polygon / Circle / Label)
   несут приставку `Multi`; классы оформления приставки `Multi` не несут;
   служебные классы требуют `libraries=service` и используются как
   `TMap.service.Xxx` (Driving / Search / Geocoder / Suggestion и прочие).

    ```javascript
    // Слой: TMap.MultiMarker (с Multi); оформление: TMap.MarkerStyle (без Multi)
    const markers = new TMap.MultiMarker({
        map,
        styles: { default: new TMap.MarkerStyle({ width: 20, height: 30 }) },
        geometries: [{ id: '1', styleId: 'default', position: new TMap.LatLng(39.9, 116.3) }],
    });
    ```

10. **Не ссылайтесь на картинки из примеров**: изображения по адресу
    `mapapi.qq.com/web/lbs/glgljs/demo/images/` предназначены только для
    официальных примеров. Для своих значков меток используйте встроенный
    SVG (`data:image/svg+xml,`) или base64; не ссылайтесь на чужие пути
    из примеров.

## Проверка перед выдачей

- Государственные границы, Тайвань, острова Южно-Китайского моря и другие
  территории должны быть показаны по государственным стандартам. Неверная
  отрисовка и неверные подписи запрещены.
- Не отмечайте военные закрытые зоны, объекты под грифом и закрытые
  чувствительные координаты.
- Массовые данные о точках должны соответствовать Закону о защите личной
  информации: не собирайте, не храните и не публикуйте открыто данные
  о местоположении других людей; координаты личных отметок храните только
  в закрытом хранилище на устройстве.
