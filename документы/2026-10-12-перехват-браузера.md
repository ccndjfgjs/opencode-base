# План реализации: перехват управления браузером

> **Для агентов-исполнителей:** ОБЯЗАТЕЛЬНЫЙ СКИЛЛ: используй executing-plans
> для реализации этого плана задача за задачей. Шаги используют синтаксис
> чекбоксов (`- [ ]`) для отслеживания.

**Цель:** дать человеку возможность забрать браузер у нейросети — и сделать
так, чтобы в этом состоянии мост **не мог даже читать страницу**, а отказ был
виден нейросети, а не молчаливым.

**Архитектура:** `handover.py` — состояние файлом рядом с настройками и
решение по каждому вызову инструмента. Лаунчер перестаёт быть глухим
проводом (`stdin=sys.stdin`) и становится посредником: читает протокол от
opencode, спрашивает `handover.decide()` и либо пропускает вызов, либо
сам отдаёт видимый отказ. Маленькое окно поверх всего пишет состояние.
Файла состояния нет — лаунчер работает **как раньше**, это выключатель.

**Стек технологий:** Python 3, PyQt6, stdio-JSON-RPC без сторонних пакетов.
Проверки — в `tools/dbapp/selftest.py`, как устроен весь проект.

**Спецификация:** `документы/2026-10-03-вкладка-программы.md`, разделы 13.9,
13.11, 13.13 (перехват), 13.4 (как человек говорит «готово»).

**Состояние на 12.10.2026:** мост работает, режим «мои сессии» проверен
вживую. Перехвата нет: поиск по `handover`, `перехват`, `предпросмотр`,
`hand_over` в `browsers.py` даёт **ноль совпадений**.

## Глобальные ограничения

- Каждый `subprocess` с `text=True` обязан иметь `errors="replace"` —
  12.10.2026 приведены к одному виду все 21 вызов, новый код без этого не
  принимается.
- Файл состояния — рядом с настройками opencode, тем же приёмом, что
  `mcp-browsers.json` и `mcp-browsers-token.txt`.
- Лишнего stdout в лаунчере быть не должно: stdout — это протокол, весь
  журнал только в stderr.
- Ширина строки в проекте не ограничена (679 строк длиннее 79, максимум
  147) — переносить код ради цифры 79 не нужно.
- Строки в таблице инструкций читаются в utf-8; проверять только через
  selftest, не глазами.
- Комментарии и docstring'и — на русском, тон прямой: что делает и почему,
  без «возможно, целесообразно».
- Запрещено выдумывать имена инструментов Playwright MCP. Список
  allowlist в HANDOVER **пустой по построению**: в §13.3 разрешены только
  `Browser.getVersion` и `Target.getTargets`, но это команды CDP, а не
  инструменты Playwright MCP, и как они называются у пакета — не проверено.
  Пустой список честнее выдуманного.

```python
# -*- coding: utf-8 -*-
"""Перехват управления браузером: состояние и решение по вызову.

Зачем. В режиме «мои сессии» нейросеть видит твои вкладки и твои входы в
аккаунтах. Пока перехвата нет, «стоп, я сам» сказать нечем: мост
формально продолжает видеть страницу, на которой ты вводишь пароль.
Этот модуль — только логика: чем управляется браузер прямо сейчас и можно
ли отдавать нейросети вот этот вызов. Ни процессов, ни окон — здесь
нечего ломать перезапуском.

Где состояние. Файлом рядом с настройками opencode, тем же приёмом, что
выбор браузера (mcp-browsers.json) и токен расширения
(mcp-browsers-token.txt): переживает перезапуск и виден обеим сторонам —
и лаунчеру, и окошку. Порт или память не годятся: порт кто-то займёт, а
память умрёт вместе с процессом.

Два состояния и третье, молчаливое.
  ai       — обычная работа нейросети, всё можно;
  handover — браузер у человека, мост обязан отказать любому вызову;
  файла нет — перехват выключен, мост работает как раньше. Это
              выключатель: сломанная новая часть не уронит рабочий мост.
Неизвестное значение в файле — тоже отказ, а не «можно»: неизвестность не
имеет права молча стать разрешением.
"""
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

#: Файл состояния рядом с настройками opencode.
STATE_NAME = "mcp-browsers-handover.txt"

#: Управляет нейросеть — обычная работа.
AI = "ai"

#: Управляет человек. Любой вызов инструмента — отказ.
HANDOVER = "handover"

#: Что мы понимаем. Всё остальное — отказ, а не догадка.
KNOWN: tuple[str, ...] = (AI, HANDOVER)

#: Текст отказа. Показывается нейросети как ошибка инструмента, поэтому
#: обязан отвечать на два вопроса: что случилось и что делать.
REFUSAL = (
    "ПЕРЕХВАТ: браузером сейчас управляет человек. Ты не можешь ни читать "
    "страницу, ни нажимать в ней, ни снимать её, ни выполнять в ней код. "
    "Дождись, пока человек нажмёт «Готово, можно», и только потом "
    "продолжай. Перехват снимает только человек."
)

#: Пояснение в самом файле — чтобы человек, открыв его, понял, что это.
#: Каждая строка помечена решёткой и отбрасывается по правилу, а не по
#: первым словам: именно угадывание «по первым словам» однажды скормило
#: расширению русскую строку как токен, и отказ был молчаливым.
STATE_HEADER: tuple[str, ...] = (
    "Кем управляется браузер нейросети: ai или handover.",
    "handover — человек взял браузер себе, мост отказывает любому вызову.",
    "ai — обычная работа нейросети, всё можно.",
    "Файла нет — перехват выключен, мост работает как раньше.",
    "Неизвестное значение = отказ: неизвестность не становится «можно».",
    "Меняет это окошко «Браузер нейросети — перехват», не руками.",
)


def state_path(dest: Path) -> Path:
    """Где лежит состояние для этой папки настроек."""
    return Path(dest) / STATE_NAME


def read_state(dest: Path) -> str | None:
    """Состояние. None — файла нет, перехват выключен.

    Читается по правилу: строки с решёткой и пустые отбрасываются, берётся
    первая осмысленная. Значение, которого мы не знаем, возвращается как
    есть — не приводим к 'ai' молча. Решать, что с ним делать, будет
    decide, и решит он «отказ».
    """
    path = state_path(dest)
    try:
        text = path.read_text(encoding="utf-8")
    except OSError:
        return None
    for line in text.splitlines():
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        return line.lower()
    return None


def write_state(dest: Path, value: str) -> list[str]:
    """Записать состояние. Возвращает сообщения человеку.

    Непонятное значение отвергается и файл не трогает: писать в файл
    состояния мусор — значит запереть браузер или, хуже, открыть его
    кому попало.
    """
    if value not in KNOWN:
        return [f"Не знаю такого состояния: «{value}». "
                f"Можно только: {', '.join(KNOWN)}."]
    lines = [f"# {row}" for row in STATE_HEADER]
    lines += ["", value, ""]
    state_path(dest).write_text("\n".join(lines), encoding="utf-8")
    who = "человек взял браузер" if value == HANDOVER else "нейросеть работает"
    return [f"Перехват: {who}."]


def describe(state: str | None) -> str:
    """Строка для окошка: что сейчас происходит."""
    if state is None:
        return ("Перехват выключен: файла состояния нет. Нажми «Я взяла», "
                "чтобы включить.")
    if state == HANDOVER:
        return "Браузер у тебя. Нейросеть не может ничего сделать."
    if state == AI:
        return "Браузер у нейросети: она читает страницу и нажимает."
    return f"Не понимаю состояние «{state}» — считаю его перехватом."


@dataclass(frozen=True)
class Verdict:
    """Решение по одному вызову инструмента."""

    allowed: bool
    reason: str


def decide(tool: str, state: str | None) -> Verdict:
    """Можно ли отдать нейросети этот вызов в этом состоянии.

    Инструмент сюда не передаётся ради имени в тексте отказа: имя инструмента
    не меняет ответ. Пришло на будущее — когда у перехвая появятся свои
    исключения, решение будет смотреть, ЧТО просят, а не только кто управляет.
    """
    del tool  # решение пока не зависит от имени инструмента
    if state is None or state == AI:
        return Verdict(True, "")
    if state == HANDOVER:
        return Verdict(False, REFUSAL)
    return Verdict(False, f"{REFUSAL} (в файле состояния написано «{state}»)")


def refusal_result(reason: str) -> dict:
    """Ответ протокола на отказанный вызов.

    Через result с isError, а не через error. Причина проверена: протокольную
    ошибку клиент может съесть молча, а молчащий отказ опаснее отказа явного —
    снаружи всё выглядит работающим. Так отказ доходит до модели как текст
    самого инструмента.
    """
    return {"content": [{"type": "text", "text": reason}], "isError": True}
```

- [ ] **Шаг 1: напиши падающие проверки**

Подставной дочерний процесс — простейший сервер протокола: отвечает на
любой `tools/call` строкой `FAKE-OK`. Нужен, чтобы проверка шла без сети,
без npx и без браузера: лаунчер запускает его вместо моста.

```python
    # ---- 8ф-2. Перехват: живой прокси с подставным дочерним процессом
    echo("\n--- 8ф-2. Перехват: посредник в лаунчере ---")
    _hv2 = Path(tempfile.mkdtemp(prefix="selftest-handover-live-"))
    try:
        import handover as _hv2m  # noqa: PLC0415
        _fake = _hv2 / "fake_bridge.py"
        _fake.write_text(
            "import json, sys\n"
            "for line in sys.stdin:\n"
            "    if not line.strip():\n"
            "        continue\n"
            "    msg = json.loads(line)\n"
            "    if msg.get('method') == 'tools/call':\n"
            "        ans = {'jsonrpc': '2.0', 'id': msg.get('id'),\n"
            "               'result': {'content': [{'type': 'text',\n"
            "                                        'text': 'FAKE-OK'}],\n"
            "                          'isError': False}}\n"
            "        sys.stdout.write(json.dumps(ans, ensure_ascii=False)"
            " + chr(10))\n"
            "        sys.stdout.flush()\n",
            encoding="utf-8")
        _launcher = (core.program_root() / "tools" / "dbapp" / "launchers"
                     / "browsers_bridge_launcher.py")
        check(_launcher.is_file(), "лаунчер моста браузеров на месте")

        def _ask(dest, tool, answer_id=7, seconds=25):
            """Один вызов инструмента через настоящий лаунчер."""
            env = dict(os.environ)
            env["OPENCODE_CONFIG_DIR"] = str(dest)
            env["BROWSERS_BRIDGE_TEST_CMD"] = (
                f"{sys.executable} {_fake}")
            proc = subprocess.Popen(
                [sys.executable, str(_launcher)],
                stdin=subprocess.PIPE, stdout=subprocess.PIPE,
                stderr=subprocess.PIPE, env=env, cwd=str(dest),
                text=True, encoding="utf-8", errors="replace", bufsize=1,
                startupinfo=core.hidden_startupinfo())
            answers: dict[object, dict] = {}
            import threading

            def reader():
                assert proc.stdout is not None
                for line in proc.stdout:
                    try:
                        msg = json.loads(line)
                    except ValueError:
                        continue
                    if isinstance(msg, dict) and "id" in msg:
                        answers[msg["id"]] = msg

            threading.Thread(target=reader, daemon=True).start()
            assert proc.stdin is not None
            proc.stdin.write(json.dumps(
                {"jsonrpc": "2.0", "id": answer_id, "method": "tools/call",
                 "params": {"name": tool, "arguments": {}}}) + "\n")
            proc.stdin.flush()
            deadline = time.monotonic() + seconds
            while time.monotonic() < deadline and answer_id not in answers:
                if proc.poll() is not None:
                    break
                time.sleep(0.1)
            try:
                proc.stdin.close()
            except OSError:
                pass
            proc.wait(timeout=20)
            return answers.get(answer_id) or {}

        _t = _hv2 / "настройки"
        _t.mkdir()
        check(_hv2m.state_path(_t).is_file() is False,
              "до записи файла состояния нет")

        # Перехват выключен — вызов доходит до браузера.
        _hv2m.write_state(_t, _hv2m.AI)
        _ans = _ask(_t, "browser_snapshot")
        _txt = ""
        for _c in (_ans.get("result") or {}).get("content") or []:
            if isinstance(_c, dict):
                _txt += str(_c.get("text") or "")
        check("FAKE-OK" in _txt and "ПЕРЕХВАТ" not in _txt,
              "состояние ai: вызов проходит до браузера")

        # Перехват включён — до браузера не доходит ничего.
        _hv2m.write_state(_t, _hv2m.HANDOVER)
        _ans = _ask(_t, "browser_snapshot")
        _txt = ""
        for _c in (_ans.get("result") or {}).get("content") or []:
            if isinstance(_c, dict):
                _txt += str(_c.get("text") or "")
        check("ПЕРЕХВАТ" in _txt and "FAKE-OK" not in _txt,
              "состояние handover: вызов НЕ доходит до браузера, "
              "нейросеть получает отказ")
        _is_err = (_ans.get("result") or {}).get("isError")
        check(_is_err is True, "и отказ помечен как ошибка инструмента")

        # Отказ относятся все инструменты, какие есть, а не избранные.
        for _tool in ("browser_evaluate", "browser_take_screenshot",
                      "browser_navigate", "browser_type"):
            _ans = _ask(_t, _tool, answer_id=8)
            _txt = ""
            for _c in (_ans.get("result") or {}).get("content") or []:
                if isinstance(_c, dict):
                    _txt += str(_c.get("text") or "")
            check("ПЕРЕХВАТ" in _txt and "FAKE-OK" not in _txt,
```

```python
def serve(argv: list[str], dest: Path) -> int:
    """Посредник: протокол от opencode проходит через нас.

    Зачем клин. Пока мост получал stdin/stdout напрямую, вклиниться между
    «нейросеть попросила» и «браузер сделал» было негде — мост был глухим
    проводом. Теперь решение принимается на каждом вызове инструмента.

    Как. Запускаем мост с трубами, два потока: ответы моста идут наружу без
    изменений, наши вопросы читаем сами. Запись в stdout одна на всех, под
    замком: иначе наш отказ и чужой ответ могут склеиться в одну строку, а
    строка протокола — это целое сообщение.

    Ответы моста не разбираются и не пересылаются заново: мы их пропускаем
    байт в байт. Своё мы добавляем только там, где отказываем.
    """
    try:
        proc = subprocess.Popen(
            argv, stdin=subprocess.PIPE, stdout=subprocess.PIPE,
            stderr=None, startupinfo=core.hidden_startupinfo(),
            text=True, encoding="utf-8", errors="replace", bufsize=1,
        )
    except OSError as exc:
        say(f"мост не запустился: {exc}")
        return 1

    out_lock = threading.Lock()

    def to_opencode(payload: dict) -> None:
        with out_lock:
            sys.stdout.write(json.dumps(payload, ensure_ascii=False) + "\n")
            sys.stdout.flush()

    def pump_child() -> None:
        """Ответы моста наружу без изменений — это тоже протокол."""
        assert proc.stdout is not None
        try:
            for line in proc.stdout:
                with out_lock:
                    sys.stdout.write(line)
                    sys.stdout.flush()
        except (OSError, ValueError):
            pass

    threading.Thread(target=pump_child, daemon=True).start()

    assert proc.stdin is not None
    try:
        for line in sys.stdin:
            if not line.strip():
                continue
            message = None
            try:
                message = json.loads(line)
            except ValueError:
                message = None
            if isinstance(message, dict) and message.get("method") == "tools/call":
                params = message.get("params") or {}
                tool = str(params.get("name") or "")
                verdict = handover.decide(
                    tool, handover.read_state(dest))
                if not verdict.allowed:
                    say(f"перехват: отказываю инструменту {tool}")
                    to_opencode({"jsonrpc": "2.0", "id": message.get("id"),
                                 "result": handover.refusal_result(
                                     verdict.reason)})
                    continue
            proc.stdin.write(line)
            proc.stdin.flush()
    except (BrokenPipeError, OSError):
        pass
    finally:
        try:
            proc.stdin.close()
        except OSError:
            pass
    return proc.wait()
```

```python
# -*- coding: utf-8 -*-
"""Окно перехвата: «Я взяла» и «Готово, можно».

Зачем отдельное окно, а не кнопка в программе. Человек должен видеть его в
тот момент, когда тянется к браузеру, — то есть поверх всего, а не во вкладке
программы, которую надо сначала открыть. Маленькое, с двумя кнопками.

Состояние окно только пишет: читает и решает — handover, а мост — лаунчер.
Так поломка в интерфейсе не может открыть браузер кому попало: написать
непонятное значение handover откажется.

Перестало быть нужным — закрой окно. Состояние от этого не меняется: браузер
остаётся там, где был.
"""
from __future__ import annotations

import sys
from pathlib import Path

from PyQt6.QtCore import QTimer
from PyQt6.QtWidgets import QApplication, QPushButton, QVBoxLayout, QWidget

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE))

import handover  # noqa: E402 — рядом лежит
import ui  # noqa: E402 — рядом лежит

#: Как часто окно перечитывает состояние. Не для красоты: файл может
#: поменяться снаружи — например, человек поправил его руками — и окно
#: обязано показать правду, а не своё воспоминание.
REFRESH_MS = 700


class HandoverWindow(QWidget):
    """Две кнопки и подпись состояния, поверх всех окон."""

    def __init__(self, dest: Path, parent=None) -> None:
        super().__init__(parent)
        self.dest = Path(dest)
        self.setWindowTitle("Браузер нейросети — перехват")
        self.setMinimumWidth(460)
        self.setWindowFlag(self.windowFlags()
                           | __import__("PyQt6.QtCore", fromlist=["Qt"])
                           .Qt.WindowType.WindowStaysOnTopHint)

        box = QVBoxLayout(self)
        box.setSpacing(8)
        box.addWidget(ui.label(
            "Браузером управляет либо нейросеть, либо ты. Пока он у тебя, "
            "мост не может ни читать страницу, ни нажимать в ней.",
            wrap=True))
        box.addWidget(ui.line())
        self.state_label = ui.label("", wrap=True)
        box.addWidget(self.state_label)
        box.addWidget(ui.line())

        self.take_btn = QPushButton("Я взяла")
        self.take_btn.setObjectName("primary")
        self.done_btn = QPushButton("Готово, можно")
        row = box  # кнопки кладём одной строкой, обе видны сразу
        row.addWidget(self.take_btn)
        row.addWidget(self.done_btn)
        box.addStretch(1)

        self.take_btn.clicked.connect(
            lambda: self._set(handover.HANDOVER))
        self.done_btn.clicked.connect(lambda: self._set(handover.AI))

        self.timer = QTimer(self)
        self.timer.setInterval(REFRESH_MS)
        self.timer.timeout.connect(self.refresh)
        self.timer.start()
        self.refresh()

    def _set(self, value: str) -> None:
        """Записать состояние. Непонятное значение handover отвергнет."""
        for line in handover.write_state(self.dest, value):
            self.state_label.setText(line)
        self.refresh()

    def refresh(self) -> None:
        state = handover.read_state(self.dest)
        self.state_label.setText(handover.describe(state))
        # Кнопка недоступна, а не спрятана: причина видна, и непонятно
        # молчащее окно не получится.
        self.take_btn.setEnabled(state != handover.HANDOVER)
        self.done_btn.setEnabled(state != handover.AI)


def main() -> int:
    dest = Path(sys.argv[1]) if len(sys.argv) > 1 else (
        __import__("browsers").find_settings_dir())
    app = QApplication(sys.argv)
    app.setWindowIcon(ui.app_icon())
    ui.apply_dark_theme(app)
    window = HandoverWindow(dest)
    window.show()
    return app.exec()


if __name__ == "__main__":
    sys.exit(main())
```

```markdown
В режиме «мои сессии» браузер — твой, с твоими входами в аккаунтах. Поэтому

1. **Сразу остановиться.** Не повторять тот же вызов, не пробовать другой
```
