# Папка «записи»

Сами записи библиотеки. Одна запись — один файл `ncp-*.md` внутри папки-темы.

Тема — это папка, и она создаётся сама: вписал `личное/животные` — появилась папка `животные`. Вложенность одна: `личное/животные` можно, `личное/дом/животные` — нет.

Всё, что лежит в `записи/` без слова `личное`, — общие знания, они переезжают вместе с программой. Папка `личное/` — про конкретного человека, и её содержимое **не копируется в новые базы**.

Писать руками сюда не стоит: записи создаёт инструмент `ncp_save`, он же пишет оглавление и указатель. Руками созданный файл мост не увидит.

Заготовка для новой записи — `../шаблоны/ЗАПИСЬ.md`.
