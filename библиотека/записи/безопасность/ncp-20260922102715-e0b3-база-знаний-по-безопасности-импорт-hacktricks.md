# База знаний по безопасности (импорт hacktricks)

## Содержание

В базе знаний лежит импортированный справочник HackTricks — ~1046 файлов в `знания/Техника/Безопасность/`. Это не запись-конспект, а целая картотека по темам. Когда запрос касается безопасности, находишь тему и открываешь нужный файл напрямую по пути.

Как пользоваться: открой `знания/Техника/Безопасность/_подсказки-безопасность.md` — это карта направлений, дальше в нужной папке ищи файл по имени атаки (имена английские).

Темы и папки:
- Веб-уязвимости (XSS, SQLi, SSRF, SSTI, XXE, JWT, OAuth, CSRF, IDOR, десериализация, CSP, файловые включения/загрузка, smuggling, перехват аккаунтов) → `Веб/`
- Сетевые службы и порты (SSH, RDP, SMB, FTP, DNS, SMTP, HTTP, Docker, Redis, MySQL, Kerberos, WinRM и почти все порты) → `Сеть/` (файлы `pentesting-*`)
- Windows/Active Directory (привилегии, кража учётных данных, lateral movement, NTLM, UAC, Cobalt Strike) → `Windows/`
- Linux (эскалация привилегий, контейнеры, процессы, post-exploitation) → `Linux/`
- macOS (red teaming, эскалация, persistence) → `macOS/`
- Android/iOS-проверки → `Мобилки/`
- Бинарный эксплойт, реверс, стеганография → `Бинарка-реверс/`
- Криптография и блокчейн → `Крипта-блокчейн/`
- Методологии, reverse shells, фаззинг, форенсика, железо, радио → `Методологии/`
- Анонимность и OPSEC → `Приватность/`
- Безопасность ИИ/LLM (промпт-инъекции, MCP, fuzzing) → `AI/`

Правило: читать только нужный файл по теме, весь раздел в память не грузить.
