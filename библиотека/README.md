# Библиотека NCP

Это самостоятельная локальная библиотека, которой управляет нейросеть.

- `NCP.md` — полный протокол: сущности, форматы, правила чтения и записи.
- `АКТИВНАЯ-ПАМЯТЬ.md` — короткий контекст для продолжения работы после новой
  сессии или сжатия контекста.
- `КАТАЛОГ.md` — список знаний для человека.
- `index.json` — машинный индекс.
- `записи/<тема>/` — полные знания.
- `входящие/` — необработанные материалы.
- `архив/` — устаревшие или неактивные записи.
- `журнал/` — история операций.
- `шаблоны/` — образцы файлов.

Библиотека работает через инструменты плагина OpenCode: поиск, чтение, создание,
обновление, контрольная точка и переиндексация. Подробности — в `NCP.md`.
