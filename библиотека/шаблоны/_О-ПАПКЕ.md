# Папка «шаблоны»

Заготовки для новых записей. Здесь лежит `ЗАПИСЬ.md` — образец, с которого начинается новая запись.

Образец отвечает на три вопроса, на которые запись обязана ответить сама:

1. **что это** — одна строка сверху, по ней запись находят;
2. **когда пригодится** — без этого запись не найдут в нужный момент, и она будет мёртвым грузом;
3. **что внутри** — чтобы не перечитывать всю запись, чтобы решить, читать ли её дальше.

Пользоваться шаблоном необязательно: `ncp_save` принимает запись и без него. Но если в базе он лежит, записи пишутся ровнее — особенно по сроку годности и признаку «устарело».

Правило про содержание одно: **одна мысль — одна запись**. Если не влезает в одну, значит мыслей две.
