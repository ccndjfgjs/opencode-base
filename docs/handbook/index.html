Справочник по программе

Полное описание интерфейса и всего, что программа умеет: память, мосты, серверы MCP, агенты, навыки, команды, устройство базы.

Это окно на PyQt6, которое создаёт и обслуживает локальную базу долговременной памяти для ИИ-ассистента. База — обычная папка с файлами: знания, навыки, правила, библиотека записей. Программа подключает её к OpenCode, ставит мосты и следит, чтобы ничего не потерялось.

Что здесь лежит

Десять разделов. Каждый отвечает на свой вопрос и не повторяет соседние.

Интерфейс

Все восемь вкладок: что на каждой, из каких блоков состоит, какие кнопки и что они делают. Плюс диалоги, которые открываются поверх окна.

Память

Три типа памяти — NCP, Obsidian, Hindsight. Чем отличаются, что создаётся в базе при каждом выборе, как работает банк памяти Hindsight.

Мосты

Одиннадцать мостов, которые лежат внутри программы: OBS, Android, браузеры, OmniRoute, LMArena и другие. Что дают и что требуют.

Серверы MCP

Полный реестр из 55 серверов по двенадцати категориям: что даёт каждый, какие требования, какая лицензия. И 22 отклонённых с причинами.

Агенты

Тринадцать ролей для OpenCode — от проектировщика до охранника. Кто что делает, какие права и как вызывать.

Навыки

Сорок три навыка: когда какой применяется и что получается на выходе. Индекс, по которому модель выбирает нужный.

Команды

Пять слэш-команд OpenCode: запомнить факт, показать память, создать проект, записать работу, просканировать сессии.

Структура базы

Из чего состоит база: восемнадцать папок, указатели знаний, архив потерянных привязок, что не публикуется в репозиторий.

Обслуживание

Самотест, обновление программы, скрипты проверок, подмодуль obs-mcp и перенос базы на другой компьютер.

Как запустить

Двойной щелчок по Управление-базой.cmd в корне базы. Файл сам находит Python с PyQt6 — сначала во вложенных средах, потом среди установленных, затем в PATH — и открывает окно без консоли.

Запасной способ — запустить tools\dbapp\Запустить-окно.pyw через Python, в котором стоит PyQt6.

Чего программа не делает. Не удаляет и не перемещает ваши папки, не трогает папки проектов и резервные копии, не пишет в служебные папки пакетов, не перезаписывает базу поверх базы и не меняет чужие файлы настроек — только добавляет своё или убирает его же.

Требования

ЧтоЗачем
Windows 10/11программа работает с реестром, ярлыками и путями Windows
Python 3 с PyQt6для окна; обычный системный Python часто не подходит
Node.jsдля плагина памяти, вспомогательных скриптов и моста OBS

Мосты из раздела Мосты лежат в репозитории, но требуют установленного приложения: мост OBS работает только с открытой студией, мост эмулятора — с запущенным эмулятором. Без этих программ сама база работает нормально, и окно честно говорит, чего не хватает.
