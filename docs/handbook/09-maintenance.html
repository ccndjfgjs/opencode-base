раздел 09

Обслуживание

Самотест, обновление, скрипты проверок, клонирование на Windows и перенос базы на другой компьютер.

Четыре вещи, которые нужны не каждый день, но рано или поздно нужны: проверить, что всё работает; обновить программу; пересобрать указатели; перенести базу на другой компьютер.

Самотест

Проверка, которая создаёт пробные базы во временной папке, подключает их и убирает за собой. Ваши файлы не трогает.

python tools\dbapp\selftest.py

Нужен тот же Python, в котором установлен PyQt6. Отчёт появляется на экране и сохраняется в selftest-report.txt — файл в .gitignore, потому что содержит реальные пути машины.

Подмодуль чинится сам. Перед проверкой программа дозабирает подмодуль obs-mcp, если клон был сделан без --recurse-submodules. Тихо, если всё на месте, и с честной строкой, если пришлось сходить в сеть.

Обновление

Вкладка «Обновление» показывает, что стоит, что доступно и что делать. Она не решает сама: берёт данные из проверенных слоёв, показывает ответ и запускает действие.

Что видноЧто значит
Кнопки выключены с причинойчеловек получает объяснение до нажатия, а не после
Прогресс с числомсколько скачано из сколького и что делается сейчас
Отмена при закрытии окнанедокачанный файл удаляется, чтобы его не приняли за годный
Только HTTPS и только github.comправило проверяется в слое скачивания, а не в окне

Лежат в tools/проверки. Часть из них — одноразовые, часть нужна регулярно.

Клонирование на Windows

Обычный git clone обрывается двумя местами. Оба известны и обходятся один раз.

Длинные пути

В знания/Техника/Безопасность/ есть файлы с очень глубокими именами — до 222 символов относительно корня. Windows держит путь в 260 символов, и клон падает на трёх файлах с сообщением unable to checkout working tree.

git config --global core.longpaths true

Подмодуль моста OBS

Исходники obs-mcp лежат подмодулем: чужой код не копируется в репозиторий, а закрепляется ссылкой на конкретный коммит.

git clone --recurse-submodules https://github.com/ccndjfgjs/opencode-base.git

Настройка submodule.recurse = true выглядит как то же самое, но на клон не работает — проверено на git 2.55.0.windows.3. Поэтому она и не выставляется: выглядела бы как починка, которой нет. Клон без флага чинит себя сам при первом запуске самотеста.

Перенос на другой компьютер

База переносится целиком: в конфигах вместо путей стоят пометки {{BASE}}, {{DESKTOP}}, {{LIBRARY}}, {{HERE}}, а настоящие пути программа подставляет при подключении. Вписывать реальный путь в эти файлы вручную нельзя — мост перестанет работать у другого человека.

Для развёртывания есть tools/deploy.js; пошагово — раздел 11 встроенной инструкции.

Если что-то не работает

СимптомЧто делать
Программа не открываетсяне найден Python с PyQt6; Управление-базой.cmd скажет, что поставить
Подключение прошло с замечаниямичаще всего занятый файл: закройте программу, в которую подключаете базу, и повторите
Список баз пуст, хотя база естьона создана не этой программой; укажите путь вручную
Нейросеть не достаёт навыкипроверьте КАРТА-БАЗЫ.md: без навигатора ассистент не знает о папке skills
Мост не отвечаетпроверьте, открыта ли программа, которой он управляет: OBS, эмулятор, редактор

Порядок при поломке. Сначала самотест — он отвечает, сломана программа или окружение. Потом отчёт: в нём видно, на каком шаге всё встало. И только потом правки — иначе лечится симптом, а не причина.
