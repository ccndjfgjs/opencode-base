Навыки

Сорок три навыка с условиями применения — и один, который загружается всегда, до первого ответа.

Навык — это инструкция для модели: когда её применять и что должно получиться. Модель не читает все сорок три подряд: есть индекс skills-index.json, по которому она выбирает нужный по сценарию задачи.

1
навык загружается всегда

Один навык обязателен. auto-memory-load загружается в начале каждой сессии, до первого ответа: он поднимает профиль, проекты и факты и выясняет состояние библиотеки. Это не по запросу — это шаг, без которого остальное работает вслепую.

Все навыки

Колонка «Когда» — это условие, при котором навык вообще уместен. Колонка «Что получается» — результат, по которому видно, сработал он или нет.

Как это работает в OpenCode

  1. Плагин памяти при запуске OpenCode копирует навыки из базы в настройки программы.
  2. Модель читает индекс и выбирает навык по сценарию.
  3. Навык подгружается целиком — вместе с правилами и примерами.
  4. Вкладка opencode, блок 5, показывает список и умеет проверить обновления навыков.

Мастер-копии лежат в skills/, каждая — папка с SKILL.md. Правка мастер-копии и правка установленной копии — разные вещи: при следующем запуске установленная перезапишется из базы.
