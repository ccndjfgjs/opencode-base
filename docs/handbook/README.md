# Справочник по программе opencode-base

Папка с описанием программы: что она умеет, как устроена и что делает
каждая кнопка. Собрано по коду и реестрам репозитория — не по памяти.

## Как открыть

**Онлайн:** [ccndjfgjs.github.io/opencode-base/handbook/](https://ccndjfgjs.github.io/opencode-base/handbook/)

**Локально:** откройте `index.html` двойным щелчком. Интернет не нужен —
все стили лежат рядом, в папке `assets`.

Навигация — в левой колонке, одинаковая на всех страницах. Внизу каждой
страницы есть переход к предыдущему и следующему разделу.

## Что внутри

| Файл | О чём |
|---|---|
| `index.html` | обзор: что за программа, цифры, карта разделов, запуск |
| `01-interface.html` | восемь вкладок, одиннадцать диалогов, точные надписи кнопок |
| `02-memory.html` | три типа памяти: NCP, Obsidian, Hindsight — разница и что на диске |
| `03-bridges.html` | одиннадцать мостов внутри программы: что дают и что требуют |
| `04-mcp-servers.html` | реестр 55 серверов по 12 категориям и 22 отклонённых |
| `05-agents.html` | тринадцать ролей для OpenCode |
| `06-skills.html` | сорок три навыка с условиями применения |
| `07-commands.html` | пять слэш-команд |
| `08-base-structure.html` | восемнадцать папок, указатели знаний, граница публичного |
| `09-maintenance.html` | самотест, обновление, проверки, перенос на другой компьютер |

## Откуда данные

- интерфейс — из `tools/dbapp/main.py`: названия вкладок, блоков, кнопок
  и флажков взяты дословно;
- память — из `core.py`, `memory_prefs.py`, `hindsight_base.py`;
- мосты и серверы MCP — из `данные/mcp-registry.json` и
  `данные/bridge-versions.json`; снимок этих двух файлов лежит в `data/`;
- категории — из `tools/dbapp/mcp_categories.py`;
- агенты — из `tools/agents/*.md`, поле `description`;
- навыки — из `skills-index.json`;
- команды — из `config/command/*.md`.

## Если что-то устарело

Справочник — снимок на 27.10.2026, версия программы 1.0.0. Цифры и списки
берутся из реестров, а не пишутся руками, поэтому пересобрать его можно
без сверки каждого абзаца.
