Память

Три типа памяти, разница между ними и что происходит на диске при каждом выборе.

У базы ровно один тип памяти. Сочетаний нет: хранилище одно, иначе никто не знал бы, куда писать. Тип выбирается при создании базы, в блоке 2 вкладки «Новая база», и запоминается в настройках окна — в следующий раз он уже выбран.

NCP

Библиотека записей. Папка библиотека, поиск и мост NCP, инструменты ncp_* и memory_*.

по умолчанию 18 папок

Obsidian

Хранилище заметок. Сама база открывается и читается в Obsidian. Папки «библиотека» нет, мост NCP не ставится.

11 папок без библиотеки

Hindsight

Внешний банк памяти. Папки «библиотека» нет, мост ходит на 127.0.0.1:8888/mcp/<банк>/.

11 папок нужен сервер

Hindsight подробнее

Это единственный тип, которому нужен отдельный сервер. Программа ставит и поднимает его сама — требование человека от 25.10.2026: не «напиши конфиг», а сделай.

Два способа установки

  • uv — отдельный модуль, Docker не нужен;
  • Docker — официальный образ, нужен запущенный Docker Desktop.

Выбор показывается в шаге 2 прямо при создании базы: человек узнаёт о цене в диске и памяти до, а не после.

Что происходит на диске

  • MCP-сервер висит на http://127.0.0.1:8888;
  • у каждой базы свой банк: /mcp/<банк>/;
  • база данных — встроенная PostgreSQL (pg0), данные в ~/.hindsight/data/;
  • отдельно ставить PostgreSQL не нужно.

Проверка живости

Кнопка не говорит «работает», пока сервер не ответил. Проверяются два адреса:

АдресЧто значит
/health/liveпроцесс жив, база данных не трогается
/health/readyто же плюс можно выполнить SELECT 1; 200 — готов

Берётся второй: «жив» и «готов» — разные вещи, и показывать зелёную отметку по первому значило бы врать.

Ключ модели

Hindsight нужен LLM. Программа ищет подходящего домашнего OpenAI-совместимого провайдера в opencode.jsonc и передаёт его на лету через переменные HINDSIGHT_API_LLM_*. Ключ в базу не пишется.

Ограничение. Hindsight — единственный тип памяти, который без своего сервера бесполезен: папки «библиотека» нет, а мост ведёт на внешний адрес. Если сервер не поднялся, память не работает — и программа говорит об этом прямо, а не ставит зелёную отметку.
