# OpenCode_Base — локальная база памяти для opencode

Эта папка — долговременная память AI-ассистента opencode. Он сам читает её в начале
каждой сессии и сам дополняет по ходу работы. Всё хранится только локально.

## Файлы
- `КАРТА-БАЗЫ.md` — **навигатор**: что где лежит и куда что писать (начинать знакомство отсюда)
- `ПРАВИЛА-ИИ.md` — как ассистент должен себя вести в этой базе
- `profile.md` — профиль пользователя: кто, как общаться, предпочтения
- `projects.md` — краткий индекс всех проектов (описания проектов — в их папках)
- `facts.md` — факты, правила и решения (самое важное, приоритетное)
- `skills/` — **скиллы для opencode** (мастер-копии, русифицированные): `skills/<имя>/SKILL.md`
- `tools/sessions.js` — сканер сессий opencode: `node tools/sessions.js list` (все сессии: создана/использована/название/папка), `list --dir <путь>` (фильтр по папке), `delete <id>` (удалить через официальный CLI)
- `tools/dbapp/` — **окно управления базой**: создание новых баз и подключение к программам. Запуск — `Управление-базой.cmd` в корне
- `tools/deploy.js` — развёртывание базы на новом компьютере (вызывается `База.bat`, вручную не нужен)
- `ОБРАЗЕЦ-БАЗЫ.md` — **образец базы**: устройство, что куда писать, как расширять темами
- `библиотека/` — **NCP-библиотека**, которой нейросеть управляет сама: записи, поиск, каталог, активная память и восстановление контекста
- `память/` — короткая сводка «на чём остановились» (`АКТИВНАЯ-ПАМЯТЬ.md`), старое — в `архив/`
- `знания/` — материалы по областям: `Техника`, `Деньги`, `Здоровье`, `Учёба`, `Дом-и-быт`, `Документы`
- `личное/` — цели, привычки, идеи, дневник
- `журнал-решений/` — **почему** так решили (отличается от `sessions/` — там **что** делали)
- `настройки/` — стиль общения, запреты, разрешения
- `инструкции/` — **все инструкции** (этот файл и остальные, см. таблицу ниже)
- `config/` — **резервные копии конфигурации opencode** (`opencode.jsonc`, `AGENTS.md`, `plugins/memory-base.js`, `command/`, зависимости плагина). Подробности — в `инструкции/Копия-конфига.md`
- `_исходники-батников/` — тексты батников для правок (правила сборки — в `инструкции/Батники-сборка.md`)
- `sessions/` — общий лог всех завершённых сессий
- `projects/` — **структура по проектам и нейросетям**:
  - `projects/index.json` — соответствие «папка на диске ↔ проект»
  - `projects/<Проект>/_проект.md` — описание, этапы, статус проекта
  - `projects/<Проект>/<Нейросеть>/work.md` — что сделала эта нейросеть по проекту
  - `projects/<Проект>/<Нейросеть>/sessions.md` — автолог её сессий

## Скиллы
Мастер-копии скиллов хранятся здесь, в `skills/`. Плагин `memory-base.js` при каждом
запуске opencode автоматически копирует их в `~/.config/opencode/skills/` (недостающие
и изменённые; удалённые из базы — убирает оттуда). Чистый opencode подхватывает их сам.

Набор (15.09.2026): правка кода — `systematic-debugging`, `test-driven-development`,
`verification-before-completion`; планирование — `brainstorming`, `writing-plans`,
`executing-plans`; дизайн — `frontend-design`, `canvas-design`; сценарии — `scriptwriting`.
Источники: github.com/obra/superpowers (MIT), github.com/anthropics/skills, авторский.
Новый скилл = папка `skills/<имя>/SKILL.md` с фронтматтером `name` + `description`.

## Как это работает
1. **Чтение**: `profile.md`, `projects.md`, `facts.md` и короткая `библиотека/АКТИВНАЯ-ПАМЯТЬ.md` автоматически впрыскиваются в каждую сессию opencode (конфиг `instructions`).
2. **Короткая память**: инструменты `memory_*` хранят профиль, проекты и правила; плагин логирует сессии и работу нейросетей.
3. **Большая библиотека**: инструменты `library_*` ищут, читают, создают и обновляют тематические записи. Перед сжатием контекста нейросеть сохраняет контрольную точку, а после сжатия читает её и продолжает работу.
4. **Команды**: `/память` — сводка базы, `/запомнить <факт>` — добавить факт, `/проект` — создать проект, `/работа <кто что сделал>` — записать работу внешней нейросети, `/сессии` — просматривать сессии.

## Перенос и восстановление
Всё делается одним файлом — `База.bat` в корне. Он открывает меню, где нужно выбрать пункт.

- **Новый компьютер**: скачать базу, запустить `База.bat` и выбрать пункт **1**.
  Батник разложит конфиг, подставит актуальные пути (база может лежать где угодно),
  импортирует плагин памяти и скиллы, поставит зависимости из локальной копии —
  интернет не нужен. Подробно — в `инструкции/Перенос-базы.md`.
- **Конфиг сломался или потерялся** (база на месте): запустить `База.bat`, пункт **2**.
  Прежняя версия сохраняется в `~\.config\opencode\_previous-version`.
- **Импорт базы в другую программу** (Codex, Claude, Qwen и т.д.): `База.bat`, пункт **3**.
  Переносятся файлы памяти, папки базы и **скиллы** — батник сам подберёт
  подходящую папку и напишет, куда именно их положил.
- Плагин памяти сам находит базу: путь берётся из `~\.config\opencode\memory-base-path.txt`
  (его пишет батник), затем из переменной `OPENCODE_MEMORY_BASE`, затем — путь по умолчанию.
  Поэтому после переноса достаточно один раз запустить `База.bat` (пункт 1).

## Правила обращения с базой
- Ничего не удалять: только дополнять и уточнять.
- Дубликаты фактов недопустимы — перед добавлением проверять поиском.
