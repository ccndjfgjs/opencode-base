# Мосты редакторов, CapCut, Spotify, ChatGPT API, Codex и Cursor

Это не свои протоколы. Каждый мост запускает чужой опубликованный сервер
или встроенную команду редактора. Исходники в базу не копировались.
Живым редактором на 2026-10-14 ничего из этого не проверялось: зелёной
галочки нет и быть не должно, пока сервер сам не ответил.

Как нажать кнопки в окне и что сказать в терминале — в
`Окно-управления-базой.md`, разделы «Серверы MCP» и «Как просить из терминала».
Здесь — что именно запускается и чего мост не обещает.

Включение — вкладка **opencode**, блок **«Серверы MCP»**, строка моста.
**«Настроить автоматически»** делает только свою часть: проверяет, что
умеет, и записывает файл рядом с настройками. Плагин в редактор она не
ставит и готовым мост не считает. **«Включить»** только вписывает команду.
Если файла ещё нет, программа спросит, не открыть ли настройку. Затем
перезапуск opencode.

Секреты лежат рядом с настройками, обычно `C:\Users\<имя>\.config\opencode\`.
В репозиторий их не класть.

| Мост | Что запускается | Секрет или свой файл |
|---|---|---|
| `unity` | `uvx --from mcpforunityserver==10.3.0 mcp-for-unity --transport stdio` | нет |
| `unreal` | `npx -y unreal-engine-mcp-server@0.6.0-beta-e` | `mcp-unreal.txt` |
| `roblox-studio` | `%LOCALAPPDATA%\Roblox\mcp.bat` | нет, файл создаёт Studio |
| `godot` | команда `attach` из дока плагина | `mcp-godot-attach.json` |
| `tiktok` | `npx -y @getmcpads/tiktok-ads-mcp-server@2.0.1` | `mcp-tiktok.txt` |
| `capcut` | удалённый MCP, адрес даёт человек | `mcp-capcut.json` |
| `spotify` | `npx -y @xavifabregat/spotify-mcp@0.1.2` | `mcp-spotify.txt` |
| `chatgpt` | `POST https://api.openai.com/v1/responses` | `mcp-chatgpt.txt` |
| `codex` | `codex exec`, затем `codex queue` | нет, вход у самого Codex |
| `cursor` | `agent create-chat`, затем `agent -p --resume` | `mcp-cursor.txt`, ключ можно не писать |

Лаунчеры: `tools/dbapp/launchers/`. Журнал пишут в stderr. В stdout
протокола MCP лишнего текста нет.

Кнопка в окне не заменяет человека в редакторе:

| Мост | Что делает кнопка | Что остаётся человеку |
|---|---|---|
| Unity | проверяет `uvx` и вписывает команду | поставить пакет по git URL и открыть проект |
| Unreal | пишет путь в `mcp-unreal.txt`, только если в проекте есть EngineWire | собрать плагин и открыть редактор |
| Roblox Studio | вписывает команду, только если уже есть `mcp.bat` | включить сервер внутри Studio |
| Godot | пишет вставленную команду `attach` в `mcp-godot-attach.json` | скопировать её из дока плагина и открыть редактор |
| TikTok | пишет токен в `mcp-tiktok.txt`, в журнал значение не попадает | взять токен в своём кабинете |
| CapCut | пишет твой https-адрес MCP в `mcp-capcut.json` | дать адрес хоста и открыть черновик в CapCut |
| Spotify | пишет Client ID в `mcp-spotify.txt` | Premium, открытый Spotify и вход мастера пакета |
| ChatGPT API | пишет ключ и имя модели в `mcp-chatgpt.txt` | взять их в своём кабинете OpenAI |
| Codex | проверяет, что команда `codex` есть | поставить CLI и сделать `codex login` |
| Cursor | проверяет команду `agent`, ключ по желанию | поставить Cursor CLI и войти |

Если папка настроек в окне и папка, откуда лаунчер читает файл, разные,
кнопка копирует файл и туда. Содержимое в текст копии не входит.

## Unity

Источник: [CoplayDev/unity-mcp](https://github.com/CoplayDev/unity-mcp), MIT.
Не продукт Unity Technologies. Редактор: 2021.3 LTS — 6.x. Нужен `uv`.

1. Поставить Unity Hub и редактор. Вход в аккаунт нужен, программа его
   не делает. Unity 2020 из winget мосту не подходит, кнопка её не ставит.
2. В редакторе: **Window → Package Manager → Add package from git URL**:

   `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main`

3. Открыть проект. Включить сервер во вкладке **opencode**.
4. Телеметрия пакета выключается переменной `DISABLE_TELEMETRY=1`.

Без открытого редактора с пакетом лаунчер стартует сервер, но сцена
не поедет. Это не «готов».

## Unreal Engine

Источник: [ChiR24/Unreal_mcp](https://github.com/ChiR24/Unreal_mcp), MIT.
Не продукт Epic. Движок 5.0–5.8.

На 2026-10-14 в npm: `latest` = 0.5.30, `beta` = 0.6.0-beta-e.
README говорит, что 0.5.30 не совпадает с плагином 0.6. Лаунчер
закреплён на `0.6.0-beta-e` и не берёт плавающий `@beta`.

1. Epic Games Launcher можно поставить кнопкой (`EpicGames.EpicGamesLauncher`).
   Сам движок — после входа, это уже человек.
2. Скачать `EngineWire` с релизов репозитория и положить в
   `MyGame/Plugins/EngineWire/`. Открыть проект и дать ему собраться.
   Старая папка `McpAutomationBridge` к этой версии не подходит.
3. Рядом с настройками создать `mcp-unreal.txt`. Одна строка — папка
   проекта или файл `.uproject`. Если плагин лежит не внутри проекта:

   ```
   project=D:\Games\MyGame
   plugin=D:\Plugins\EngineWire
   ```

4. Включить сервер. Токен capability лаунчер в конфиг не пишет: сервер
   читает его из проекта по `UE_PROJECT_PATH`.
5. Нужен Node.js 20.19 или новее. Это поле `engines` пакета, не догадка.

## Roblox Studio

Источник: [документация Roblox](https://create.roblox.com/docs/studio/mcp),
страница обновлена 2026-10-13. Сервер встроен в Studio.

Команда для Windows оттуда же:

```
cmd.exe /c %LOCALAPPDATA%\Roblox\mcp.bat
```

1. Поставить Studio. Идентификатор winget `Roblox.RobloxStudio` снят
   2026-10-03 и сегодня не перепроверялся. Документация просит актуальную
   Studio; хватает ли старой версии каталога — неизвестно.
2. В Studio: **Assistant → … → Manage MCP Servers → Enable Studio as MCP server**.
3. Появится `mcp.bat`. Пока его нет, лаунчер отказывает и пишет, куда нажать.
4. Включить сервер во вкладке **opencode** и перезапустить opencode.

Старый `Roblox/studio-rust-mcp-server` авторы сами пометили
неразвиваемым. Исполнители кода (executor) не подключаются: это обход
платформы, не мост студии.

Клиент читает и меняет открытое место. Подключать только свой opencode.

## Godot

Источник: [hi-godot/godot-ai](https://github.com/hi-godot/godot-ai), MIT.
На PyPI 2026-10-14 пакет `godot-ai` 4.3.0. Редактор для v4 — 4.7 или новее.
Идентификатор winget `GodotEngine.GodotEngine`, версия каталога 4.7.2
взята со страницы пакета, не командой `winget show` на этой машине.

1. Поставить Godot и `uv`.
2. Положить плагин в `addons/godot_ai/` так, чтобы внутри был `plugin.cfg`.
   Брать релиз, не сырой снимок поверх старой установки. Как именно —
   в README релиза, не выдумывать.
3. **Project → Project Settings → Plugins → Godot AI**.
4. В доке нажать **Configure** или скопировать **Run this manually**.
5. Рядом с настройками создать `mcp-godot-attach.json`:

   ```json
   {
     "command": ["uvx", "...то, что написал док...", "attach", "..."]
   }
   ```

   В списке обязано быть слово `attach`. Голый
   `http://127.0.0.1:8000/mcp` README запрещает: capability так не
   передаётся. Лаунчер чужую команду не сочиняет.

Телеметрия выключается `GODOT_AI_DISABLE_TELEMETRY=true` или
`DISABLE_TELEMETRY=true`. Если док уже добавил `--disable-telemetry`,
файл не переписывать.

## TikTok

Это не игровой редактор. Мост ходит в **TikTok Business API** со своим
токеном. Скрейпер, вход в чужой аккаунт и обход проверки не делаются.

Источник: [getmcpads-com/tiktok-ads-mcp-server](https://github.com/getmcpads-com/tiktok-ads-mcp-server),
Apache-2.0. В npm на 2026-10-14 версия 2.0.1, `engines` требует Node
`>=22.12.0`. Описание пакета: чтение и отдельные записи, запись только
после предпросмотра. Живым запросом это не подтверждалось.

Официальный удалённый MCP TikTok в открытый доступ на тот день не
подтверждался, поэтому берётся самостоятельный пакет. Запросы всё равно
уходят на серверы TikTok. Приватный код через этот мост не гонять:
ему там нечего делать, а токен рекламного кабинета — секрет.

1. В кабинете Business API получить access token и App ID.
2. Рядом с настройками создать `mcp-tiktok.txt`:

   ```
   TIKTOK_ACCESS_TOKEN=...
   TIKTOK_APP_ID=...
   ```

3. Включить сервер. Лаунчер пишет в журнал только «токен прочитан»,
   само значение не печатает.

Если нужен был Effect House, а не рекламный кабинет — этого моста нет,
говорить об этом прямо, а не подменять одно другим.

## CapCut по интернету

Это монтажёр. Официального MCP у CapCut нет, и программа не ходит на
capcut.com. Облачный рендер VectCut закрытый, его адрес в документацию
не подставлен: живого адреса MCP там не нашлось.

Кнопка принимает только https-адрес, который дал твой хост. localhost,
частная сеть и страница сайта не подходят. Порт 9001 локального
VectCutAPI — это не MCP по интернету, его кнопка тоже не примет.

Токен, если хост его просит, пишется в `mcp-capcut.json`. В журнал
значение не попадает. При включении заголовок попадает в
`opencode.jsonc` на этом компьютере: иначе opencode не сможет
представиться серверу. В репозиторий этот файл не копировать.

Редактор CapCut ставится отдельно, идентификатор winget
`ByteDance.CapCut`. Версия 9.4.0.4015 снята с каталога winstall
2026-10-14, `winget show` здесь не запускался. Вход в аккаунт программа
не делает. Ролик кнопка не экспортирует: черновик открывается в CapCut
уже человеком.

Живой запрос по адресу 2026-10-14 не делался.

## Чего лаунчер не делает

- Не ставит плагин в проект сам, кроме того, что уже умела программа
  для Blender и OBS. У движков плагин или токен — шаг человека.
  CapCut по интернету тоже не ставится сам: нужен адрес хоста.
- Не ставит зелёную галочку, пока редактор не ответил.
- Не пишет настоящий путь компьютера в реестр: в команде плейсхолдеры
  `{DBAPP_PYTHON}` и `{PROGRAM}`.
- Не копирует чужой C++ / C# / Luau в базу.
- Не включает VK Музыку и Яндекс.Музыку: открытого API на включение трека нет, а частные клиенты скачивают файл. Это сюда не кладётся.
- Не открывает сайт chatgpt.com и не забирает куки браузера.
- Не передаёт Codex `danger-full-access` и Cursor `--yolo`. `--force` у Cursor только если явно попросили правки.

## Spotify, ChatGPT, Codex и Cursor

Живой ответ 2026-10-14 не проверялся. Кнопка записывает файл или проверяет команду и не ставит зелёную галочку.

### Spotify

Пакет `@xavifabregat/spotify-mcp` 0.1.2, MIT, Node 20+. Он ходит в Spotify Web API. Это не программа Spotify AB. Воспроизведение Spotify отдаёт только Premium и только уже открытому приложению.

Client ID пишется в `mcp-spotify.txt`. В журнал значение не попадает. Вход в аккаунт делает мастер пакета, не эта кнопка:

```
npx -y @xavifabregat/spotify-mcp@0.1.2 init
```

Плеер можно поставить через winget, идентификатор `Spotify.Spotify`. Версию на 2026-10-14 здесь не измеряли.

Спросить в терминале OpenCode можно так: «включи Peace Piece в Spotify». Пока вход пакета не сделан и приложение не открыто, мост трек не включит и не будет делать вид, что включил.

### ChatGPT

Это официальный API, не сайт chatgpt.com. Новый ответ — `POST https://api.openai.com/v1/responses`. Продолжение — то же, с `previous_response_id`. Имя модели копируется из кабинета, программа его не подставляет.

Ключ и модель лежат в `mcp-chatgpt.txt`. В журнал не пишутся. Запрос при включении не делается.

### Codex

Официальная команда `codex exec` создаёт новый чат и печатает ответ. `codex queue --thread <id> --message` ставит текст в уже существующий чат и ответ не ждёт: так устроена эта команда.

По умолчанию песочница `read-only`. Запись в папку — только если попросили `workspace-write`. `danger-full-access` и `--yolo` не передаются. Пароль программа не спрашивает: вход делает `codex login`.

CLI ставится через winget, идентификатор `OpenAI.Codex`. Версию здесь не измеряли.

### Cursor

Новый чат — `agent create-chat`. Команда в него — `agent -p --resume <id>`. По умолчанию режим `ask` и без `--force`. Правка файлов включается только явной просьбой в режиме агента. `--yolo` нет.

Ключ, если он нужен, лежит в `mcp-cursor.txt` и уходит переменной, не аргументом командной строки. Если вход в CLI уже есть, ключ можно не писать.

Установка CLI — страница [cursor.com/docs/cli/installation](https://cursor.com/docs/cli/installation). Редактор Cursor сам по себе команду `agent` не заменяет, поэтому кнопки «поставить редактор» у этой строки нет.

### Чего нет

VK Музыка и Яндекс.Музыка в список не вошли. У них нет открытого API, которым можно сказать «включи этот трек». Сторонние программы ходят в закрытый API и скачивают файл либо внедряются в окно плеера. Этот мост так не делает.
