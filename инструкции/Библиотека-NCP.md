# Библиотека NCP — память, которой управляет нейросеть

## Коротко

Библиотека NCP — это локальная внешняя память для нейросети. Она не изменяет
и не обучает саму модель. Вместо этого нейросеть:

1. сохраняет стойкие знания в отдельные записи;
2. строит индекс и каталог;
3. ищет и читает нужное перед ответом;
4. перед сжатием контекста сохраняет контрольную точку;
5. после сжатия читает её и продолжает работу.

Полный технический протокол — `библиотека/NCP.md`.

## Что подключается всегда

Только `библиотека/АКТИВНАЯ-ПАМЯТЬ.md` — короткая сводка текущей работы.
Полная библиотека в контекст не загружается, иначе контекст быстро закончится.

## Что лежит внутри

```
библиотека/
├── NCP.md                 полный протокол
├── README.md              короткое описание
├── АКТИВНАЯ-ПАМЯТЬ.md     мост между сессиями
├── КАТАЛОГ.md             список знаний для человека
├── index.json             индекс для инструментов
├── записи/<тема>/*.md     полные знания
├── входящие/              необработанные материалы
├── архив/                 неактивные записи
├── журнал/YYYY-MM.md      история операций
└── шаблоны/ЗАПИСЬ.md      образец записи
```

## Инструменты нейросети

- `library_status` — посмотреть состояние и активную память;
- `library_search` — найти знания;
- `library_read` — прочитать запись полностью;
- `library_save` — создать запись (с проверкой дубликатов);
- `library_update` — уточнить, заменить или архивировать запись;
- `library_checkpoint` — сохранить контекст перед сжатием;
- `library_reindex` — перестроить индекс и каталог.

## Что происходит при сжатии контекста

Плагин прямо требует от нейросети вызвать `library_checkpoint`, сохранить цель,
сделанное, решения и следующий шаг. В новую сессию файл активной памяти попадает
автоматически через `opencode.jsonc`.

## Как добавить готовую чужую базу

Если это уже NCP-библиотека:

1. положить её папку `библиотека/` в корень `OpenCode_Base`;
2. запустить `База.bat` и выбрать пункт 1 («Развернуть базу»);
3. нейросеть выполнит `library_reindex` при первой работе либо по просьбе.

Если это просто набор файлов:

1. положить их в `библиотека/входящие/`;
2. попросить нейросеть: «разбери входящие материалы в библиотеку NCP»;
3. она выделит записи, проверит дубликаты и разложит по темам.

Физическое удаление записей запрещено без подтверждения: устаревшее переносится
в архив и остаётся доступным для поиска.
