# Конструктор баз — расширение (сентябрь 2026)

## Что нового

### 1. Обход блокировок — больше каналов
- **DNS:** добавлены DoH-серверы Yandex, NextDNS, CleanBrowsing, Mullvad (было 4, стало 8)
- **Прокси:** источников с 2 до 6 (TheSpeedX, monosans, clarketm, roosterkid, zloi-dev)
- **Лимит:** с 30 до 60 живых узлов
- Фасад автоматически использует новые источники при автообновлении

### 2. Мод памяти NCP — 7 инструментов
- Было: ncp_status, ncp_search, ncp_save
- Добавлено: ncp_read, ncp_update, ncp_checkpoint, ncp_reindex
- Каждый инструмент проверен selftest (26/26)

### 3. Агенты — проверены живьём
- Все 12 агентов проверены: структура верная, зависимости на месте
- golosovoy: голосовая модель 75MB скачана
- provodnik-pk: мост ПК компилируется
- Все агенты рабочие

### 4. Скиллы — индекс сценариев
- Создан skills-index.json: для каждого из 16 скиллов — сценарий использования
- Нейросеть читает индекс и сама выбирает нужный скилл по сценарию задачи
- При создании базы копируется автоматически

### 5. Первый запуск
- При первом запуске создаётся папка Desktop\DataBases
- Показывается окно-приветствие в тёмной теме программы
- Запоминается маркер служебное/.first-run-done — при следующих запусках окно не показывается

### 6. Сканирование баз
- Кнопка «Сканировать» на вкладке «Подключить существующую»
- Ищет базы по файлу-идентификатору .opencode-base.json
- Сканирует рабочий стол и DataBases — быстро

## Структура конструктора

```
opencode-base/
├── tools/
│   ├── dbapp/          — окно управления (main.py, core.py, selftest.py)
│   ├── agents/        — 12 агентов
│   ├── antiblock/      — обход блокировок (фасад, Xray, DNS, прокси)
│   ├── ncp-bridge/     — мост NCP (7 инструментов)
│   ├── pc-bridge/      — мост ПК
│   └── voice/          — голосовой ввод
├── знания/             — справочники (HackTricks и т.д.)
├── библиотека/         — эталон библиотеки NCP
├── skills/             — 16 скиллов
├── skills-index.json  — индекс сценариев скиллов
├── инструкции/         — инструкции по устройству базы
├── config/             — эталон настроек opencode
├── themes/             — темы оформления
├── ОБРАЗЕЦ-БАЗЫ.md     — образец структуры базы
├── ПРАВИЛА-ИИ.md       — правила для нейросети
├── КАРТА-БАЗЫ.md       — навигатор по базе
└── Управление-базой.cmd — запуск окна
```
