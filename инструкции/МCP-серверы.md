# MCP-серверы: что это и когда поднимать

Этот файл подключается к **каждой** сессии автоматически, пока подключена
эта база.

Мосты (`tools/ncp-bridge`, `tools/pc-bridge`) едут с базой и работают сразу.
**MCP-серверы — другое.** Это внешние программы, которые нужно поставить и
которым нужно то, чего в базе нет. Поэтому программа **ничего не ставит
сама**: она только честно говорит, готов сервер или нет и что для него нужно.

---

## 1. Разница между тремя вещами, которые легко спутать

| Что | Где живёт | Ставится | Права |
|---|---|---|---|
| **Мост ПК** (`pc_*`) | В базе, в `tools/pc-bridge` | Уже в базе | Только чтение файлов базы, всё через спрос |
| **Мост NCP** (`ncp_*`) | В базе, в `tools/ncp-bridge` | Уже в базе | Чтение и запись в библиотеку |
| **MCP-сервер** из реестра | Внешняя программа на компьютере | Отдельно, вручную | Свои у каждого |

**Мосты и серверы — не одно и то же.** Мост живёт в базе и едет с ней.
Сервер живёт на компьютере и в базу не входит. Список серверов с требованиями
лежит в `mcp-registry.json` в корне базы.

---

## 2. Что есть в реестре

### `windows-admin` — администрирование Windows
**Что даёт:** 42 инструмента в 8 модулях — службы, журнал событий,
планировщик задач, процессы, сеть, диагностика, наблюдаемость, безопасность.
Отдельная ценность — `diagnose_service`: собирает отчёт о службе за один
вызов (статус, порт, последние ошибки, зависимости) и выдаёт гипотезу.
**Нужно:** Node.js 18+ и права администратора.
**Порог низкий.** MIT, `npx windows-admin-mcp`.
**Безопасность сделана грамотно:** перед разрушительным действием показывается
превью и требуется подтверждение кодом с таймаутом 5 минут; критические
процессы (`lsass`, `csrss`, `svchost`, `winlogon`, `smss`, `services`,
`wininit`, `TrustedInstaller`) заблокированы **даже с подтверждением**;
массовые операции ограничены 20 за вызов; ведётся аудит-лог.
**Когда поднимать:** служба не стартует, непонятно кто занял порт, надо
разобрать поток ошибок в журнале.

### `excel` — Excel
**Что даёт:** 31 инструмент, 326 операций. Power Query и M-код, Power Pivot и
DAX, сводные таблицы, диаграммы, срезы, таблицы, диапазоны, форматирование,
VBA-макросы, листы и подключения, `=PY()` в облачном движке Excel.
**Почему через настоящий Excel, а не через openpyxl:** решение на openpyxl
переписывает файл `.xlsx` напрямую и **молча теряет сводные таблицы,
диаграммы и макросы**, а Power Query, модель данных и DAX не умеет вообще.
Через COM-API работает сам Excel, поэтому всё остаётся целым.
**Нужно:** Windows, Excel 2016+ и **одноразовое разрешение доступа к VBA**
(Файл → Параметры → Центр управления безопасностью → Параметры макросов →
«Доверять доступ к объектной модели проектов VBA»).
**Когда поднимать:** таблицы, сводные, отчёты, анализ данных.

### `blender` — 3D
**Что даёт:** сцена, объекты, материалы, выполнение Python в Blender,
экспорт в GLB/FBX, поиск HDRI и текстур на Poly Haven (все CC0), модели
Sketchfab и Poly Pizza.
**Нужно:** Blender 3.0+ (**бесплатный**, blender.org), `uv`, и аддон
(`uvx mcp-for-blender install-addon`, затем включить в настройках аддонов).
**В README проекта есть готовый блок конфигурации для OpenCode.**
**Про телеметрию, чтобы не было сюрприза:** по умолчанию собирается
**минимальный анонимный** объём — случайный идентификатор установки,
идентификатор сессии, имя инструмента, успех, длительность, версии, ОС,
время. Подсказки, сгенерированный код, скриншоты и данные сцены по умолчанию
**не** собираются. Отключается полностью через `DISABLE_TELEMETRY=true`.
**Когда поднимать:** 3D-сцены, модели, рендер, ассеты для игр.

### `adobe-creativity` — Adobe
**Что даёт:** Photoshop, Lightroom, Illustrator, Firefly, Premiere, InDesign,
Express, Adobe Stock — правка изображений словами, генерация и правка
картинок, поиск ассетов, монтаж видео.
**Нужно:** приложения Adobe **и** оплаченная подписка.
**Порог высокий.** Без самих приложений серверу подключаться не к чему.

## 3. Когда поднимать сервер, а когда не надо

**Правило простое: сервер нужен тогда, когда задача физически в нём.**

| Задача | Нужен сервер? |
|---|---|
| Написать или починить код | Нет. Хватает мостов базы |
| Служба Windows не стартует, надо найти почему | **Да** — `windows-admin` |
| Собрать отчёт из таблицы Excel | **Да** — `excel` |
| Придумать цветовую палитру | Нет. Скилл `better-colors` справится |
| Отрендерить 3D-сцену | **Да** — `blender` |
| Написать текст для интерфейса | Нет. Скилл `better-writing` |

**Не поднимай сервер «на всякий случай».** Поднятый сервер занимает место в
контексте и добавляет инструменты, которые в этой задаче не понадобятся.

## 4. Как проверить, что сервер готов

1. Открыть `mcp-registry.json` и найти сервер по `id`.
2. Пройтись по его полю `requires` — там написано, что нужно и чем это
   проверяется (`node`, `uvx`, `blender.exe`, `excel.exe`).
3. Поле `ready_here` — это **снимок на дату `checked`**, а не обещание.
   Оно может устареть: поставили Blender — значение ещё `false`. **Верь
   глазам, а не этому полю.**

## 5. Чего в реестре нет и почему

| Проект | Почему нет |
|---|---|
| OpenMicro | macOS-first, другие платформы автор не тестировал. Управляет Claude Code и Codex, а не OpenCode |
| 3D-Agent с blendermcp.org | Сторонний сайт-посредник, не официальный проект. Гайда для OpenCode нет, страница предлагает платное |
| book-to-skill | 32,8 тыс. звёзд и MIT, но это **Python-конвертер** с зависимостями, а не готовый скилл. Просто скопировать нельзя |

## 6. Если хочешь добавить свой сервер

1. Дописать запись в `mcp-registry.json`: `id`, `name`, `source`, `install`,
   `license`, `why`, `requires`, `ready_here`, `verdict`.
2. `verdict` — **о требованиях, а не о текущей машине.** Формулировка вида
   «нужен Node и права админа» переносится на любой компьютер; «у меня
   работает» — нет, и вчера такие записи пришлось вычищать.
3. Вписать сервер в `opencode.jsonc` в раздел `mcp` и добавить права в
   `permission`. **Права на всё сразу не давать** — на опасные инструменты
   `ask`, как это сделано для мостов.

---

## 7. Мосты против серверов: коротко

| | Мосты | MCP-серверы |
|---|---|---|
| Едут с базой | **Да** | Нет |
| Ставятся программой | **Да**, сама | Нет, никогда |
| Готовы сразу | **Да** | Зависит от машины |
| Где список | Папки `tools/*-bridge` | `mcp-registry.json` |
| Что запрещено | — | Назначать серверу права шире, чем нужно |

**Общее правило базы то же, что и для кода: сначала проверка, потом
утверждение.** Сервер не запущен и не проверен — значит утверждать нечего.
