## 15. Программа вылетала при запуске — причина и починка

Человек сообщил: после последних правок программа открывается и сразу

11:23:23, 11:24:13, 11:24:38, 11:25:05, 11:26:00. До этого дня сбоев не было
ни одного — значит, дело в сегодняшней правке, а не в старом коде.

**Как нашёл.** Журнал Windows указал на Qt, но текста ошибки не давал:

1. Сравнил с версией из последнего коммита (git worktree на 4f08417) —
   она работает, значит виновата моя правка;
2. поставил печать после каждого этапа запуска: импорт, создание окна,
   показ. Упало на `window.show()`, при этом окно собиралось целиком;
3. минимальное окно с одной галочкой и окно с двадцатью одной — показываются
   нормально. Значит, дело не в количестве галочек и не в самом Qt;
4. поставил перехватчик исключений: PyQt **проглатывает** исключение из слота
   и закрывает программу без traceback — поэтому stderr был пуст.

**Причина, дословно:**

```
File "main.py", line 5899, in _refresh
    inside = [self.TITLES[n] for n in status if status[n]]
KeyError: 'agent:iskatel'
```

Я добавил новые возможности `agent:имя`, а подписи брались из словаря `TITLES`
прямой подстановкой. Про новые имена в словаре ничего нет — как только
`_refresh()` вызывался при открытии вкладки, происходило исключение, а PyQt
убивал приложение.

**Починка.** Добавлен `_cap_title()`: подпись ищется по цепочке TITLES →
список возможностей → само имя. Тот же помощник используется и при создании
галочек, чтобы подписи не расходились.

**Проверка после починки:**

| что | результат |
|---|---|
| песочница, реальный экран, 25 секунд | жива, stderr пуст |
| старая программа, 25 секунд | жива |
| место падения напрямую (_refresh после установки агентов) | подпись собрана, агенты в ней видны |
| вкладка окна, 10 проверок | код 0 |
| последовательность установки, 14 проверок | код 0 |
| сбои python в журнале Windows после починки | **ни одного** |

Правка перенесена в старую программу и проверена там же.

**Урок.** Новое имя в списке возможностей прошло тесты установки, но не прошло
открытие окна: словарь подписей оказался вторым, непроверенным местом, где
это имя нужно. Правило на будущее: новое имя возможности проверяется не
только установкой, но и открытием вкладки — либо словарь подписей делается
безопасным по построению, как здесь.
