# opencode-base

Программа-окно для управления долговременной памятью нейросетей. Помогает
создавать «базы памяти» для OpenCode, наполнять их знаниями и навыками,
подключать к программам-ассистентам и следить, чтобы ничего не потерялось.

> Простым языком: это «домик для памяти» вашего ИИ-ассистента. Вы создаёте
> базу один раз, кладёте туда правила, знания и навыки, а программа сама
> подключает их к ассистенту и проверяет, что всё на месте.

---

## Что умеет программа

### Вкладка «Создать новую базу»

1. Указываете папку-родитель и имя новой базы. Имя проверяется на ходу:
   программа не даст создать папку с недопустимыми знаками или занятым именем.
2. Выбираете, чем наполнить базу:
   - **Пустая база** — структура, правила и навигаторы создаются сами;
     личные файлы остаются чистыми заготовками. Знания, навыки и конфиг
     приходят из главной базы (той, где установлена программа).
   - **Скопировать содержимое существующей** — полная копия базы-образца
     вместе со скиллами и личными файлами.
3. Отмечаете, к какой программе присоединить базу. Видно, какие программы
   установлены на компьютере.
4. Решаете, делать ли ярлык на базу и где ему лежать.

Кнопка «Проверить» показывает, что именно будет создано, ничего не записывая
на диск. Кнопка «Создать базу» выполняет работу.

Сразу после создания окно переключается на подключение и подставляет новую
базу — искать путь руками не нужно.

### Вкладка «Подключить существующую»

Подключает готовую базу к выбранной программе, не трогая саму базу и не
задевая папки ваших проектов. Подключение идёт в три шага:

1. **Какую базу подключить** — из списка созданных баз или папкой вручную.
2. **Куда подключить** — в настройки OpenCode (файл `AGENTS.md`,
   `opencode.jsonc`, плагин памяти и навыки копируются в папку программы).
3. **Какие навыки подключить** — что именно перенести. Неотмеченные навыки
   не удаляются, а уходят в `_previous-version\skills`, откуда их можно вернуть.

Прежние файлы памяти программы перед подключением сохраняются в
`_previous-version` — ничего не пропадает.

### Вкладка «Мост NCP»

Мост NCP — маленькая программа-переводчик, которая умеет читать библиотеку
знаний напрямую из базы (поиск, сохранение, обновление записей). Мост лежит
отдельно и базу не трогает. Программа создаёт его в выбранной папке и сразу
прогоняет проверки.

### Чего программа не делает

- Не удаляет и не перемещает ваши папки.
- Не трогает папки проектов.
- Не пишет в служебные папки пакетов (`npm`, `node_modules`).
- Не перезаписывает базу поверх базы.
- Не изменяет чужие файлы настроек — только добавляет своё или убирает его же.

## Требования

- Windows 10/11.
- Python с установленным **PyQt6** (для окна). Обычный системный Python часто
  не подходит — в нём нет PyQt6.
- Git (для разработки).

---

## Запуск

Самый надёжный способ — двойной щелчок по файлу `Управление-базой.cmd`,
который сам находит Python с PyQt6 (во вложенных средах, среди установленных
Python, затем в PATH) и открывает окно без консоли.

Запасной способ — запустить файл `Запустить-окно.pyw` через Python
с установленным PyQt6.

## Проверка работы

    python selftest.py

Нужен тот же Python, в котором установлен PyQt6. Все проверки должны быть
пройдены; отчёт появляется на экране и сохраняется в `selftest-report.txt`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `core.py` | логика без окон: создание и подключение баз, ярлыки, мост NCP, список созданных баз |
| `ui.py` | оформление окна: цвета, шрифты, мелкие блоки |
| `main.py` | само окно и все вкладки |
| `opencode_caps.py` | возможности OpenCode: команды, мосты, агенты |
| `make_shortcut.py` | создание ярлыков на рабочий стол |
| `selftest.py` | автоматическая проверка программы |
| `Запустить-окно.pyw` | запуск окна без консоли |
| `Управление-базой.cmd` | поиск нужного Python и запуск окна |

### Что попадает в новую базу

- **17 папок** — разделы базы и подпапки внутри них.
- **9 областей знаний** — Техника, Деньги, Здоровье, Учёба, Дом-и-быт,
  Документы, Люди, Имущество, Экстренное.
- **Два навигатора** — `КАРТА-БАЗЫ.md` (что где лежит) и `ПРАВИЛА-ИИ.md`
  (как поведение). Они нужны, чтобы нейросеть сразу понимала устройство базы.
- **Пояснения `_О-ПАПКЕ.md`** в каждой папке — короткие объяснения, что туда кладут.
- **Заготовки `_ШАБЛОН-….md`** — пустые карточки под личные данные: люди,
  банки, документы, страховки, техника, здоровье и другие.
- **Скиллы** (навыки) — из главной базы, все, у которых есть `SKILL.md`.
- **Конфиг с плагином памяти** — пустые базы наполняются знаниями, скиллами,
  настройками и записями библиотеки из главной базы автоматически; личные
  файлы (`profile.md`, `facts.md`, `projects.md`) остаются пустыми заготовками.

## Почему не теряются прошлые данные

- Прежние файлы при подключении сохраняются в `_previous-version`.
- Ярлыки создаются напрямую, без командной строки — поэтому русские буквы
  и длинное тире «—» в путях не портятся.
- Мост NCP копирует образец из `tools\ncp-bridge` и подставляет настоящий
  путь к библиотеке сам, поэтому работает с любого места.

## FAQ

**Программа не открывается**
Значит, не найден Python с PyQt6. `Управление-базой.cmd` ищет его сам и
покажет, что нужно поставить.

**Подключение прошло с замечаниями**
В отчёте видно, что не удалось. Чаще всего это занятый файл: закройте
программу, в которую подключаете базу, и повторите.

**Список созданных баз пуст, хотя база есть**
Значит, база создана не этой программой — такие в список не попадают.
Укажите путь вручную в нижнем поле вкладки подключения.
