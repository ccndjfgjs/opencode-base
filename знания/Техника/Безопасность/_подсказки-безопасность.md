# Карта подсказок: безопасность (HackTricks)

Источник: HackTricks с GitHub, только `.md`, картинок `images/` нет — ссылки на них в тексте ведут в никуда.

Как пользоваться агенту: определи направление ниже, открой нужную папку, в ответе дай путь `знания/Техника/Безопасность/...`. Весь текст в память не грузи.

- **Веб** — папка `Веб/` — веб-уязвимости, SQL-инъекции, XSS, SSRF: смотри при любой работе с вебом
- **Сеть** — папка `Сеть/` — сетевые службы, Nmap, перехват трафика, Wi-Fi: смотри при работе с сетью
- **Windows** — папка `Windows/` — защита и проверка Windows: смотри при задачах про Windows
- **macOS** — папка `macOS/` — защита macOS: смотри при задачах про macOS
- **Linux** — папка `Linux/` — защита Linux: смотри при задачах про Linux
- **Мобилки** — папка `Мобилки/` — мобильные приложения Android/iOS: смотри при мобильных задачах
- **Бинарка-реверс** — папка `Бинарка-реверс/` — бинарники, реверс, стеганография: смотри при анализе файлов
- **Крипта-блокчейн** — папка `Крипта-блокчейн/` — криптография и смарт-контракты: смотри при крипто-задачах
- **Методологии** — папка `Методологии/` — методологии проверки, фаззинг, форензика, Python: смотри сначала при любой проверке
- **Приватность** — папка `Приватность/` — приватность и OPSEC: смотри при вопросах анонимности
- **AI** — папка `AI/` — безопасность ИИ-агентов: смотри при задачах про ИИ
