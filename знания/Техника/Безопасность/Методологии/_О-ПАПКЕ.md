# Папка «Методологии» — как вообще делается проверка

146 файлов. Это единственный раздел, который советуют открывать первым
при любой проверке: не «как сломать», а «в каком порядке смотреть».

| подпапка | что внутри |
|---|---|
| `generic-methodologies-and-resources/` | 4 файла в корне: `pentesting-methodology` (главный), `fuzzing`, `threat-modeling`, `side-channel-attacks-on-messaging-protocols` |
| `generic-methodologies-and-resources/external-recon-methodology/` | 4: утечки баз, секреты в GitHub, поиск по исходникам |
| `generic-methodologies-and-resources/basic-forensic-methodology/` | 10 + 5 вложенных: дампы памяти (Volatility), разбор файловых систем, pcap, разбор форматов (`.pyc`, office, pdf, png, zip, discord-кэш), Windows-реестр |
| `generic-methodologies-and-resources/pentesting-network/` | 14: IPv6, DHCPv6, спуфинг LLMNR/NBT-NS/mDNS, обход сегментации, обход IDS |
| `generic-methodologies-and-resources/phishing-methodology/` | 10: гомографы, клонирование сайта, документы, угон буфера; отдельно — атаки на ИИ-агентов через режимы агента и MCP |
| `generic-methodologies-and-resources/python/` | 9 + `bypass-python-sandboxes/` (4): выход из песочниц, десериализация Keras |
| `generic-methodologies-and-resources/pentesting-wifi/` | 3: evil twin, Nexmon на Android |
| `generic-hacking/` | 6: брутфорс, эксфильтрация, туннели, плейн-текст из архивов; внутри `reverse-shells/` (6) |
| `hardware-physical-access/` | физические атаки и `firmware-analysis/` (6): загрузчики, MediaTek, Synology |
| `todo/` | 12 файлов недописанного: burp-suite, interesting-http, rust-basics, test-llms; внутри `hardware-hacking/` (8), `radio-hacking/` (10 + `flipper-zero/`), `industrial-control-systems-hacking/` (2) |
| `welcome/` | 2: об авторе и о ценностях HackTricks |
| `banners/` | 1: учебные баннеры |

**Осторожно с `todo/`.** Это черновик самого HackTricks — файлы там
заведены, но часть не дописана. Признак: тема интересная, а файла
с содержанием нет. `welcome/` и `banners/` — не методики вовсе.

Когда смотреть: всегда, когда непонятно, с чего начать проверку.
