# Папка «AI» — безопасность ИИ

Атаки на ИИ-системы и на инструменты агента. Здесь нет «классики» — всё
про то, что появилось вместе с моделями и MCP.

В корне 14 файлов:

| файл | о чём |
|---|---|
| `AI-llm-architecture/` | пронумерованный курс: токенизация, эмбеддинги, внимание, дообучение, LoRA |
| `AI-MCP-Servers` | серверы MCP: как расширяют возможности агента и что с этим делать атакующему |
| `AI-Models-RCE` | выполнение кода через модель или через её формат обмена |
| `AI-Assisted-Fuzzing-and-Vulnerability-Discovery` | фаззинг с помощью модели |
| `Web-Black-Box-AI-Pentester-Bots` | готовые боты для чёрного ящика |
| `AI-Risk-Frameworks` | frameworks оценки рисков ИИ |
| `AI-Burp-MCP` | Burp через MCP: разбор трафика глазами агента |
| `KYC-Bypass-Using-AI` | обход проверки личности (KYC) |
| `AI-Prompts`, `AI-Deep-Learning`, `AI-Supervised-Learning-Algorithms`, `AI-Unsupervised-Learning-Algorithms`, `AI-Reinforcement-Learning-Algorithms`, `AI-Model-Data-Preparation-and-Evaluation`, `README` | устройство и обучение моделей — контекст, без которого атаки непонятны |

Когда смотреть: задача про безопасность агента, MCP-сервера, промпты,
RCE через модель или через инструмент агента.
