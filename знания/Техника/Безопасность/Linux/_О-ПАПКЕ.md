# Папка «Linux» — защита Linux

69 файлов. В корне файлов нет: всё разложено по подпапкам, и порядок
подпапок совпадает с порядком работы — это перечисление системы по шагам.

| подпапка | что внутри |
|---|---|
| `linux-basics/` | команды, переменные окружения; внутри `bypass-linux-restrictions/` и `linux-privilege-escalation/` |
| `main-system-information/` | чек-лист повышения прав, модули ядра, `sudo`-злоупотребления; внутри `kernel-lpe-cves/` |
| `user-information/` | uid/rid/suid, Linux-Active-Directory, ssh-agent; внутри `interesting-groups-linux-pe/` |
| `software-information/` | PAM, SELinux, Splunk, Logstash, FreeIPA, Electron/CEF |
| `network-information/` | разведка сети и сокетов, Cisco vManage |
| `processes-crontab-systemd-dbus/` | перечисление процессов, инъекция в d-bus |
| `interesting-files-permissions/` | Capabilities, suid, ld.so.conf, NFS с no_root_squash, SELinux |
| `post-exploitation/` | пусто в корне, всё внутри `linux-post-exploitation/` |
| `containers-namespaces/` | runc и containerd: выход из контейнера; внутри `container-security/` |

Порядок работы: `linux-basics` → `main-system-information` →
`user-information` → `software-information` → `interesting-files-permissions`.
Файлы про CVE живут в `main-system-information/kernel-lpe-cves/`, общий
список — в `main-system-information/linux-privilege-escalation-checklist.md`.

Когда смотреть: Linux-хост, контейнер, повышение прав на Linux.
